📡 다중화 (Multiplexing) — FDM / TDM / CDM

다중화(Multiplexing)란 하나의 전송로(채널)에
여러 개의 신호를 동시에 전송하는 기술.
대역폭·시간·코드 자원을 효율적으로 분할하여 전송 효율을 높임.
🎯 핵심 3대 방식 한눈에
FDM
주파수 분할
· 신호: 아날로그
· 분할: 주파수
· 동기: 불필요
· 용도: 라디오·TV·CATV
TDM
시분할
· 신호: 디지털
· 분할: 시간 슬롯
· 동기: 필요
· 용도: T1/E1·PCM
CDM
코드 분할
· 신호: 디지털
· 분할: 고유 코드
· 동기: 필요
· 용도: CDMA 이동통신
📡 FDM — Frequency Division Multiplexing
전체 대역폭을 여러 개의 작은 주파수 대역으로 나누고,
각 신호를 서로 다른 주파수로 변조하여 동시에 전송.
✅ 장점
· 구현 간단·저비용
· 동기화 불필요
· 아날로그 신호 그대로 전송
❌ 단점
· 가드밴드(Guard Band) 필요 → 대역폭 낭비
· 상호변조 잡음(IM noise) 발생
· 채널 간 누화(Crosstalk) 우려
💡 Guard Band(가드밴드): 인접한 채널 사이에 두는 비어있는 주파수 대역. 채널 간 간섭 방지 목적
⏱ TDM — Time Division Multiplexing
전송 채널을 시간 단위(타임 슬롯)로 분할하여
각 단말기에 슬롯을 순차적·반복적으로 할당.
🔍 동기식 TDM vs 통계적 TDM (시험 빈출!)
구분 동기식 TDM
Synchronous		 통계적 TDM
Statistical / Asynchronous
슬롯 할당 고정 (단말마다 정해진 슬롯) 동적 (데이터 있는 단말에만 할당)
주소 정보 불필요 (슬롯 순서로 식별) 필요 (어느 단말 데이터인지 표시)
효율 낮음 (빈 슬롯 발생 가능) 높음 (낭비 없음)
구현 복잡도 간단 복잡 (버퍼·주소처리 필요)
활용 PCM, T1/E1, 음성통신 데이터 통신, 패킷망
✅ 장점
· 디지털 신호 다중화에 최적
· 가드밴드 불필요
· 대역폭 효율 좋음
❌ 단점
· 정밀한 동기화 필수
· 슬립(Slip) 발생 시 데이터 손실
· 동기식은 빈 슬롯 낭비
🔐 CDM — Code Division Multiplexing
각 사용자에게 고유한 직교 코드(Orthogonal Code)를 할당하여
동일 주파수·동일 시간에 다수가 통신하는 방식.
→ 확산 스펙트럼(Spread Spectrum) 기술 기반
동작 원리
① 송신: 데이터 × 고유 코드 → 확산 신호로 전송
② 수신: 같은 코드로 역확산 → 원래 데이터 복원
③ 다른 코드는 잡음으로 처리되어 자동 제거
✅ 장점
· 보안성 우수 (코드 모르면 복원 불가)
· 잡음·간섭에 강함
· 주파수 효율 높음
· 다중경로 페이딩에 강함
❌ 단점
· 구현 복잡 (코드 동기화 필요)
· 원근 문제(Near-Far Problem)
· 전력 제어 필수

💡 추가: WDM (광통신용)
WDM (Wavelength Division Multiplexing) — 파장 분할 다중화
· 광섬유에서 여러 파장의 빛을 동시에 전송 (FDM의 광버전)
· CWDM (Coarse, 8~16채널) / DWDM (Dense, 32~160채널)
· 광통신 백본망에서 사용 (대용량 장거리)
🔑 다중화(Multiplexing) vs 다원접속(Multiple Access)
· 다중화: 하나의 송신측이 여러 신호를 묶어 전송 (송신측 시점)
· 다원접속: 여러 사용자가 하나의 채널을 공유 (수신측 시점)
· 기술은 같지만 관점 차이: FDM → FDMA, TDM → TDMA, CDM → CDMA
⚠ 시험 핵심 포인트
· FDM = 주파수 분할, 가드밴드 필요, 아날로그 (라디오·TV)
· TDM = 시간 분할, 동기화 필요, 디지털 (T1/E1)
· CDM = 코드 분할, 직교 코드, 보안↑·잡음↑ (CDMA)
· 통계적 TDM = 데이터 있는 단말에만 슬롯 할당 (효율↑) — 최다 출제
· 가드밴드 = 채널 간 간섭 방지용 비어있는 주파수
· 무선 다원접속(FDMA/TDMA/CDMA)에는 WDMA가 없음 (WDM은 광통신)
· OFDM은 FDM의 직교형 — 가드밴드 불필요 (4G LTE·Wi-Fi·5G)
