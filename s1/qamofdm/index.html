🌐 QAM / OFDM

📶 QAM — 직교 진폭 변조 (Quadrature Amplitude Modulation)
진폭(ASK)과 위상(PSK)을 동시에 변조해 하나의 심볼에 더 많은 비트를 싣는 방식. 90° 위상차를 갖는 두 반송파(I : cos, Q : sin)에 각각 데이터를 실어 합성하므로 "직교(Quadrature)" 라 부른다.
방식신호점 수 (M)심볼당 비트필요 SNR주 사용처
16QAM164 bit낮음LTE, Wi-Fi 기본
64QAM646 bit보통디지털 CATV, LTE
256QAM2568 bit높음DOCSIS 3.x, Wi-Fi 5
1024QAM102410 bit매우 높음Wi-Fi 6, 5G NR
진수를 올리면? — 심볼당 비트가 늘어 전송 속도는 빨라지지만, 성상도의 신호점 간 거리가 좁아져 잡음에 취약해지고 더 높은 S/N이 필요하다. 전송 속도와 잡음 내성은 교환 관계.
⚠ 기출 — QAM은 위상 기준이 필요하므로 동기 검파만 사용한다. "비동기 검파도 사용한다"는 설명은 틀림.
📡 OFDM — 직교 주파수 분할 다중화
고속의 데이터를 다수의 직교하는 협대역 부반송파(Subcarrier) 로 나누어 병렬 전송하는 방식. 각 부반송파는 저속이 되므로 심볼 주기가 길어져 다중경로 페이딩에 강해진다.
직교 조건 (Orthogonality)
Δf = 1Ts
부반송파 간격 Δf 가 심볼 주기 Ts 의 역수일 때, 각 부반송파의 스펙트럼 정점에서
다른 모든 부반송파의 값이 0 이 된다 → 스펙트럼이 겹쳐도 간섭 없음
⚖ OFDM vs FDM — 기출 최다
구분FDMOFDM
부반송파 관계서로 독립 (겹치면 안 됨)직교 (겹쳐도 무방)
보호대역(Guard Band)필요불필요
대역폭 효율낮음약 50% 이상 우수
구현아날로그 필터 뱅크IFFT / FFT (디지털)
다중경로 페이딩취약강함 (CP 사용)
⚠ 기출 함정 — "OFDM은 직교성을 사용하여 FDM보다 대역폭 효율이 좋지 않다" → 틀림. OFDM이 FDM보다 대역폭 효율이 좋다.

✅ OFDM 장점

• 주파수 선택적 페이딩에 강함
• 보호대역 불필요 → 높은 대역 효율
• CP(Cyclic Prefix, 보호구간) 삽입으로 심볼 간 간섭(ISI) 방지
• IFFT/FFT로 구현 → 디지털 회로로 간단
• 부반송파별 적응 변조 가능

⚠ OFDM 단점

• PAPR(첨두전력 대 평균전력비)이 높음 → 전력증폭기 부담
• 주파수 오프셋 · 위상잡음에 민감 (동기 정밀도 요구)
• CP만큼 전송 효율 손실
• 도플러 천이에 취약

SC-FDMA — LTE 상향링크(단말 → 기지국) 전송 방식. OFDM의 높은 PAPR 문제를 개선해 단말 전력증폭기 부담을 줄인다. 하향링크는 OFDMA. 기출 단골
📻 OFDM 적용 사례
분야적용
무선 LANWi-Fi 802.11a / g / n / ac / ax
이동통신LTE 하향(OFDMA) · 상향(SC-FDMA), 5G NR, WiMAX
방송유럽 DVB-T, 디지털 라디오 DAB, DMB
유선ADSL / VDSL (DMT 방식)
⚠ 기출 함정 — 한국 지상파 디지털 TV는 OFDM이 아니다. 한국은 미국식 ATSC 를 채택해 변조는 8-VSB, 단일 캐리어 방식이다. OFDM은 유럽식 DVB-T의 특징.
📝 시험 포인트
• "고속 신호를 다수의 직교하는 협대역 반송파로 다중화" → OFDM
• OFDM은 FDM보다 대역폭 효율이 좋다 (보호대역 불필요)
• OFDM 최대 단점 = 높은 PAPR → 해결책이 LTE 상향의 SC-FDMA
• 한국 DTV = ATSC / 8-VSB / 단일캐리어 (OFDM 아님)
• 16QAM=4bit, 64QAM=6bit, 256QAM=8bit
