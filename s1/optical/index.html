💡 광통신 이론 — 시스템 · 광원 · 수광 · 증폭 (1과목)

광섬유가 길이라면, 광통신 이론은 그 길 위를 달리는 차와 신호등이다. 전기를 빛으로 바꾸는 광원, 빛을 다시 전기로 되돌리는 수광소자, 중간에서 힘을 보태는 광증폭기 — 이 셋이 핵심이다.
🔗 광통신 시스템 구성
[전기신호] │ ▼ 광 송신기 ── 구동회로 + 광원(LED / LD) ── 전기 → 빛 (E/O 변환) │ ▼ 광섬유 전송로 ── 코어 안에서 전반사로 진행 · 손실과 분산 발생 │ ▼ 광 중계기 / 광증폭기(EDFA) ── 약해진 빛을 다시 키움 │ ▼ 광 수신기 ── 수광소자(PIN-PD / APD) + 증폭·판정 ── 빛 → 전기 (O/E 변환) │ ▼ [전기신호]
광통신의 기본 방식은 IM-DD(Intensity Modulation - Direct Detection) — 빛의 세기(강도)를 변화시켜 정보를 싣고, 수신에서는 그 세기를 그대로 검출한다. 전파처럼 주파수·위상을 쓰지 않는다는 점이 출제 포인트다.
💡 광원 — LED vs LD
항목LED (발광 다이오드)LD (레이저 다이오드)
발광 원리자연 방출 (Spontaneous)유도 방출 (Stimulated)
스펙트럼 폭넓음 (수십 nm)매우 좁음 (수 nm 이하)
출력작음큼
지향성 · 결합효율퍼짐 → 결합 손실 큼직진성 우수 → 결합 효율 높음
변조 속도느림 (~수백 Mbps)빠름 (수 Gbps 이상)
온도 특성둔감 (안정적)민감 — 온도 제어 회로 필요
수명 · 가격길고 저렴짧고 비쌈
주 용도다중모드 · 단거리 LAN단일모드 · 장거리 간선
⚠ 기출 포인트 — 스펙트럼 폭이 좁을수록 재료분산이 작다. 그래서 장거리에는 반드시 LD 를 쓴다. "LED가 장거리에 유리하다"는 보기는 오답이다.
📷 수광소자 — PIN-PD vs APD
항목PIN-PDAPD (애벌런치 PD)
내부 증배없음 (이득 1)있음 — 애벌런치 증배로 수십~수백 배
수신 감도보통높음 (약한 빛도 검출)
동작 전압낮음 (수 V)높음 (수십~수백 V)
잡음적음증배 잡음 발생
온도 특성안정민감 — 이득이 온도에 따라 변함
용도단거리 · 저비용장거리 · 고감도
짝으로 외우기 — 단거리 = LED + PIN-PD, 장거리 = LD + APD. 둘 다 "장거리 쪽이 성능은 좋지만 비싸고 온도에 민감하다"는 같은 성격을 갖는다.
🎛️ 광 변조 방식
방식원리특징
직접 변조
Direct		 LD의 구동 전류를 직접 변조해 빛의 세기를 바꿈 구조 간단·저렴. 단, 처프(Chirp) 로 파장이 흔들려 분산이 커짐 → 저속·단거리
외부 변조
External		 LD는 일정하게 켜 두고, 바깥의 변조기(마흐젠더 등)로 빛을 차단·통과 처프가 적어 고속·장거리에 유리. 비쌈
🔊 광증폭기 · 중계
종류내용
EDFA
어븀 첨가		 1550 nm 대역 전용. 빛을 전기로 바꾸지 않고 광 그대로 증폭(O/E/O 불필요)
여러 파장을 한꺼번에 증폭 → WDM의 필수 부품 기출
라만 증폭기광섬유 자체의 유도 라만 산란을 이용. 넓은 대역, 분산형 증폭
SOA반도체 광증폭기. 소형이지만 잡음이 큼
3R 재생 중계기 Reshaping(파형 정형) · Retiming(타이밍 복원) · Regeneration(재생) — 전기로 바꿔 완전 복원
📖 광증폭기 vs 재생중계기 — 광증폭기는 세기만 키운다(잡음도 같이 커짐). 재생중계기는 전기로 바꿔 파형·타이밍까지 복원하지만 느리고 파장마다 장비가 필요하다. WDM처럼 여러 파장을 한 섬유에 실을 때는 EDFA 가 압도적으로 유리하다.
🌈 광 다중화 — WDM 계열
방식파장 간격 · 채널용도
WDM파장이 다른 빛을 한 섬유에 동시 전송FDM의 광 버전
CWDM저밀도간격 넓음(약 20 nm), 채널 수 적음저가·단거리. 온도 제어 불필요
DWDM고밀도간격 좁음(0.8 nm 이하), 수십~수백 채널장거리 대용량 간선. EDFA와 함께 사용
🧮 광 파워 예산 (Link Budget) — 계산 유형
송신 출력 − 총 손실 ≥ 수신 감도
단위는 dBm (0 dBm = 1 mW) · 손실은 dB 로 단순 덧셈
📖 예제 — 송신 출력 0 dBm, 수신 감도 −28 dBm, 광섬유 0.25 dB/km로 80 km, 융착 접속 8개(각 0.1 dB), 커넥터 2개(각 0.5 dB)일 때 여유(Margin)는?
① 허용 손실 = 0 − (−28) = 28 dB
② 총 손실 = (0.25 × 80) + (0.1 × 8) + (0.5 × 2) = 20 + 0.8 + 1 = 21.8 dB
③ 여유 = 28 − 21.8 = 6.2 dB → 링크 성립

광 파워미터수신단의 절대 광 출력[dBm]
광원(LS)파워미터와 짝을 이뤄 구간 총 손실 측정
융착 접속기광섬유를 아크 방전으로 녹여 접합. 접속 손실 0.05~0.1 dB

📝 시험 포인트
• 광통신 기본 = IM-DD (강도 변조 · 직접 검파)
