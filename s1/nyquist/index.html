📡 나이퀴스트 / 샤논 채널용량 공식

나이퀴스트 (Nyquist)
잡음이 없는 채널
C = 2B · log2M
C : 채널 용량 [bps]
B : 대역폭 [Hz]
M : 신호 레벨 수 (진수)
샤논 (Shannon)
잡음이 있는 채널
C = B · log2(1 + S/N)
C : 채널 용량 [bps]
B : 대역폭 [Hz]
S/N : 신호대 잡음비
📊 나이퀴스트 vs 샤논 비교
구분 나이퀴스트 샤논
채널 조건 잡음 없음 (이상적) 잡음 있음 (실제)
공식 C = 2B · log₂M C = B · log₂(1+S/N)
핵심 변수 M (신호 레벨 수) S/N (신호대 잡음비)
문제 키워드 "신호 레벨", "진수",
"M단계"		 "신호대 잡음비",
"S/N", "dB"
공통점 대역폭(B) 증가 → 채널용량(C) 증가
🔢 log₂ 값 암기표 (시험 필수)
값 log₂ 결과 이유
log₂(2) 1 2¹ = 2
log₂(4) 2 2² = 4
log₂(8) 3 2³ = 8
log₂(16) 4 2⁴ = 16
log₂(32) 5 2⁵ = 32
log₂(64) 6 2⁶ = 64
