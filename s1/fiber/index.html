🔦 광섬유 — 구조 · 파라미터 · 모드 · 손실

🧅 구조와 전송 원리
┌─────────────────────────────┐ │ 피복 Jacket (보호·완충) │ │ ┌───────────────────────┐ │ │ │ 클래드 Cladding n₂ │ │ ← 굴절률 작음 │ │ ┌─────────────────┐ │ │ │ │ │ 코어 Core n₁ │ │ │ ← 굴절률 큼 (빛이 지나는 길) │ │ └─────────────────┘ │ │ │ └───────────────────────┘ │ └─────────────────────────────┘ 반드시 n₁ > n₂

코어의 굴절률이 클래드보다 커야 경계면에서 전반사(Total Internal Reflection) 가 일어나 빛이 밖으로 새지 않고 코어 안에 갇혀 진행한다. 이것이 광섬유의 유일한 전송 원리다.

✅ 광섬유의 장점

• 광대역 — 수 THz급, 대용량 전송
• 저손실 — 1550nm에서 0.2 dB/km
• 전자기 유도 무관 — 잡음·누화 없음
• 도청 곤란 — 보안성 우수
• 가늘고 가벼움 · 부식 없음
• 중계 간격이 김 (수십~100km)

⚠ 단점

• 접속·분기가 어렵다 (융착 접속기 필요)
• 기계적 강도가 약하고 구부림에 취약
• 전기를 함께 보낼 수 없음(급전 불가)
• 시험·측정 장비가 고가 (OTDR)
• 단면을 눈으로 보면 위험 (적외선)

📐 광학적 파라미터 — 계산 4종
파라미터공식의미
임계각
θc		 θc = sin⁻¹n₂n₁ 이 각보다 크게 입사해야 전반사. 경계면 법선 기준
개구수
NA		 NA = √(n₁² − n₂²) = n₁√(2Δ) 집광 능력 — 빛을 얼마나 넓은 각도에서 받아들이는가 기출
수광각
θa		 θa = sin⁻¹(NA) 광섬유 입구에서 받아들일 수 있는 최대 입사각 (공기 n₀=1)
비굴절률차
Δ		 Δ = n₁ − n₂n₁ 보통 0.2~1 % 수준. 클수록 NA가 커지고 모드분산도 커진다
규격화 주파수
V		 V = 2πaλ × NA a = 코어 반지름. V < 2.405 이면 단일모드
모드 수
M		 SI: M ≈ V²2   GI: M ≈ V²4 계단형이 언덕형보다 모드가 2배 많다
📖 기출 계산 — 코어 n₁ = 1.50, 클래드 n₂ = 1.48 인 광섬유의 개구수와 수광각은?
① NA = √(1.50² − 1.48²) = √(2.25 − 2.1904) = √0.0596 ≈ 0.244
② θa = sin⁻¹(0.244) ≈ 14.1°
③ 임계각 θc = sin⁻¹1.481.50 = sin⁻¹(0.9867) ≈ 80.6°
④ 비굴절률차 Δ = 1.50−1.481.50 ≈ 1.33 %
⚠ 자주 틀리는 것 — 개구수(NA)가 클수록 빛을 많이 모아 결합 효율은 좋아지지만, 들어오는 모드가 많아져 모드분산이 커지고 대역폭은 좁아진다. 무조건 좋은 것이 아니다.

📝 시험 포인트
• n₁ > n₂ (코어 > 클래드) 여야 전반사 — 광섬유의 유일한 원리
• NA = √(n₁²−n₂²) = 집광 능력, 수광각 = sin⁻¹(NA)
• V < 2.405 → 단일모드, 모드 수 SI = V²2 · GI = V²4
• 단일모드 = 코어 8~10μm · 장거리 · LD / 다중모드 = 굵고 · 단거리 · 모드분산
• 레일리 산란은 λ⁻⁴ 비례 → 장파장이 유리
• 1310nm 분산 최소 / 1550nm 손실 최소(0.2dB/km) — 바꿔 쓰면 오답
• 단일모드에는 모드분산이 없고 색분산(재료+도파로) 이 대역폭을 결정
