1과목 정보전송일반

  1. 1번다음 중 전송 제어문자의 내용으로 옳은 것은?

    1. ① SYN : 문자 동기 유지
    2. ② STX : 해딩의 시작 및 텍스트의 시작
    3. ③ ETX : 텍스트의 시작을 표시
    4. ④ EOT : 전송시작 및 데이터 링크의 초기화 표시

    정답 ① — SYN(Synchronous Idle)은 문자 동기 유지에 사용. STX=본문시작, ETX=본문끝, EOT=전송종료

  2. 2번양자화 잡음의 개선 방법으로 틀린 것은?

    1. ① 양자화 스텝을 크게 한다
    2. ② 비선형 양자화 방법을 사용한다
    3. ③ 선형양자화와 압신방식을 같이 사용한다
    4. ④ 양자화 스텝수가 2배로 증가할 때마다 6[dB]씩 개선된다

    정답 ① — 양자화 스텝을 크게 하면 양자화 잡음이 커진다. 스텝을 작게 해야 잡음이 줄어든다.

  3. 3번동기식 전송(Synchronous Transmission)에 대한 설명으로 틀린 것은?

    1. ① 전송속도가 비교적 낮은 저속 통신에 사용한다
    2. ② 긴 블록(또는 프레임)을 하나의 비트열로 전송할 수 있다
    3. ③ 데이터 묶음 앞쪽에는 반드시 동기문자가 온다
    4. ④ 한 묶음으로 구성하는 글자들 사이에는 휴지 간격이 없다

    정답 ① — 동기식 전송은 고속 통신에 사용. 저속 통신에는 비동기식 전송을 사용한다.

  4. 4번FEC(Forward Error Correction) 기법에서 사용하는 오류 정정부호가 아닌 것은?

    1. ① CRC
    2. ② LDPC
    3. ③ Turbo Code
    4. ④ Hamming Code

    정답 ① — CRC(순환중복검사)는 오류 검출 코드이지 정정 코드가 아니다. LDPC, Turbo Code, Hamming Code는 오류 정정 코드.

  5. 5번이동통신이나 위성통신에서 사용되는 무선 다원 접속(Radio Multiple Access)방식에 해당되지 않는 것은?

    1. ① FDMA
    2. ② TDMA
    3. ③ CDMA
    4. ④ WDMA

    정답 ④ — WDMA(Wavelength Division Multiple Access)는 광통신에서 사용하는 파장분할 다중접속. 무선 다원접속은 FDMA/TDMA/CDMA.

  6. 6번짝수 패리티 비트의 해밍코드로 0011011을 받았을 때, 오류가 정정된 정확한 코드는?

    1. ① 0111011
    2. ② 0011000
    3. ③ 0101010
    4. ④ 0011001

    정답 ④ — 해밍코드 오류 검출/정정 계산 결과 0011001이 정확한 코드.

  7. 7번다음 중 광 강도 변조의 설명으로 맞는 것은?

    1. ① 파장이 서로 다른 광 신호간에 상호 간섭을 받지 않는 변조 방식이다
    2. ② 여러 광 신호를 하나의 광섬유에 전송하기 위해 행하는 변조 방식이다
    3. ③ 광 신호에 포함된 직류성분을 제거하기 위해 행하는 변조방식이다
    4. ④ 발광 디바이스의 휘도를 신호에 따라 변화시키는 휘도 변조 방식이다

    정답 ④ — 광 강도 변조(Intensity Modulation)는 발광 디바이스의 빛의 세기(휘도)를 신호에 따라 변화시키는 방식.

  8. 8번5[kHz]의 음성신호를 재생시키기 위한 표본화 주기는?

    1. ① 225[μs]
    2. ② 200[μs]
    3. ③ 125[μs]
    4. ④ 100[μs]

    정답 ④ — 나이퀴스트 정리: 표본화 주파수 = 2×5kHz = 10kHz. 표본화 주기 = 1/10,000 = 100[μs]

  9. 9번설계자가 감쇠 특성을 고려하여 통신시스템을 설계할 때 반영하지 않아도 되는 사항은?

    1. ① 수신기의 전자회로가 신호를 검출하여 해석할 수 있을 정도로 수신된 신호는 충분히 커야 한다
    2. ② 오류가 발생하지 않을 정도로 신호는 잡음보다 충분히 커야 한다
    3. ③ Pair 케이블을 조밀하게 감을수록 비용이 낮고 성능은 좋아진다
    4. ④ 감쇠는 주파수가 증가함에 따라 증가하는 특성을 보인다

    정답 ③ — 케이블을 조밀하게 감으면 비용은 낮아질 수 있으나 성능(전자기 간섭 등)이 좋아진다고 단정할 수 없다.

  10. 10번전리층을 이용한 통신에 가장 많이 사용되는 주파수대는?

    1. ① VLF대
    2. ② HF대
    3. ③ VHF대
    4. ④ UHF대

    정답 ② — 전리층 반사를 이용한 단파(HF, 3~30MHz) 통신이 전리층을 이용한 통신에 가장 많이 사용된다.

  11. 11번채널용량에 대한 설명으로 옳지 않은 것은?

    1. ① 통신용량이라고도 하며 단위로는 [bps]를 사용한다
    2. ② 수신측에 전송된 정보량은 상호 정보량의 최대치이다
    3. ③ 채널용량을 증가시키기 위해서는 대역폭을 줄이고 S/N비를 증가시켜야 한다
    4. ④ 잡음이 있는 채널에서는 Shannon의 공식을 사용하여 채널 용량을 계산한다

    정답 ③ — 채널용량 증가 = 대역폭 증가 + S/N비 증가. 대역폭을 줄이면 채널용량이 감소한다.

  12. 12번다음 중 다원접속 기술방식이 다른 것은?

    1. ① Token
    2. ② Polling
    3. ③ CSMA/CD
    4. ④ Round-robin

    정답 ③ — Token, Polling, Round-robin은 제어 방식(충돌 없음). CSMA/CD는 경쟁 방식(충돌 발생 후 감지).

  13. 13번이동통신망에서 발생하는 페이딩 중 고층 건물, 철탑 등 인공구조물에 의하여 발생하는 페이딩은?

    1. ① Long-term Fading
    2. ② Short-term Fading
    3. ③ Rician Fading
    4. ④ Mis-term Fading

    정답 ② — Short-term Fading(단기 페이딩)은 다중경로 전파에 의한 페이딩으로 인공구조물 등에 의해 발생.

  14. 14번디지털 통신망에서 발생하는 Slip에 대한 설명으로 옳지 않은 것은?

    1. ① 일종의 버퍼인 ES의 오버플로우나 언더플로우에 의한 데이터 손실을 Slip이라고 한다
    2. ② Slip이 제어되지 않으면 프레임 동기 손실을 유발한다
    3. ③ 1프레임 단위로 발생하는 Slip을 Controlled Slip이라 한다
    4. ④ Slip을 방지하는 방법으로 SSB(Single Side Band)방법을 사용한다

    정답 ④ — Slip 방지는 동기화 방법을 사용. SSB는 단측파대 변조 방식으로 Slip과 관계없다.

  15. 15번증폭기와 정궤환 회로에서 βA>1이면 출력되는 파형은?

    1. ① 출력되는 파형의 진동이 서서히 사라진다
    2. ② 출력되는 파형은 진폭에 클리핑이 일어난다
    3. ③ 지속적으로 안정적인 파형이 발생한다
    4. ④ 출력되는 파형은 서서히 진폭이 작아진다

    정답 ② — βA>1이면 발진이 점점 커져 포화상태에 이르러 클리핑이 발생한다. βA=1일 때 안정적인 발진 유지.

  16. 16번상호변조왜곡 방지 대책으로 가장 적합한 것은?

    1. ① 입력 신호의 레벨을 높인다
    2. ② 전송시스템에 FDM 방식을 사용한다
    3. ③ 송수신 장치를 선형영역에서 동작시킨다
    4. ④ 필터를 이용하여 통과대역 내의 신호를 걸러낸다

    정답 ③ — 상호변조왜곡(IMD)은 비선형 소자에서 발생. 선형영역에서 동작시키면 왜곡을 최소화할 수 있다.

  17. 17번UTP 케이블 특징이 틀린 것은?

    1. ① 차폐 기능을 지원
    2. ② 8가닥 선으로 구성
    3. ③ 트위스트페어 케이블의 일종
    4. ④ 전송길이는 최대 100[m] 이내

    정답 ① — UTP = Unshielded Twisted Pair. U는 비차폐(Unshielded)를 의미. 차폐 기능은 STP(Shielded)에 있다.

  18. 18번Flip-Flop과 관계가 없는 것은?

    1. ① RAM
    2. ② Decoder
    3. ③ Counter
    4. ④ Register

    정답 ② — Flip-Flop은 RAM(기억), Counter(계수), Register(저장)에 사용. Decoder는 조합논리회로로 Flip-Flop과 무관.

  19. 19번레이더 또는 위성통신에 이용되며, Kn밴드, K밴드, Ku밴드, X밴드, L밴드 등을 사용하는 파는?

  20. 20번통신망 구성요소 중 괄호 a-b-c-d-e가 순서대로 바르게 짝지어진 것은?
