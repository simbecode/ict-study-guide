100문항5과목해설 포함

1과목 정보전송일반

  1. 1번다음 중 전송부호 형식의 조건으로 틀린 것은?

    1. ① 대역폭이 작아야 한다
    2. ② 부호가 복잡하고 일관성이 있어야 한다
    3. ③ 충분한 타이밍 정보가 포함되어야 한다
    4. ④ 에러의 검출과 정정이 쉬워야 한다

    정답 ② — 전송부호 조건: 대역폭 소, 간단하고 일관성 있는 부호, 타이밍 정보 포함, 에러 검출/정정 용이. 복잡한 부호가 아닌 간단한 부호여야 함.

  2. 2번회선 부호화(Line Coding)에 대한 설명으로 틀린 것은?

    1. ① 기저대역 신호가 전송채널로 전송되기 적합하도록 아날로그 신호 형태로 변환하는 방식이다
    2. ② 디지털 데이터를 디지털 신호로 변환하는 방식이다
    3. ③ 단극형, 극형, 양극형(쌍극형) 등의 범주가 있다
    4. ④ 디지털 신호의 기저대역 전송을 위해 신호를 만드는 과정이다

    정답 ① — 회선 부호화(Line Coding)는 디지털 데이터를 디지털 신호로 변환하는 것. 아날로그 신호 형태가 아닌 디지털 신호 형태로 변환.

  3. 3번전송매체의 대역폭이 12,000[Hz], 두 반송파 주파수 사이의 간격이 최소 2,000[Hz]일 때 2진 FSK 신호의 보오율[baud]과 비트율[bps]은? (전이중방식, 각 방향 동일 대역폭)

    1. ① 4,000[baud], 4,000[bps]
    2. ② 4,000[baud], 8,000[bps]
    3. ③ 10,000[baud], 10,000[bps]
    4. ④ 10,000[baud], 16,000[bps]

    정답 ① — 전이중: 각 방향 6,000Hz. 2진 FSK: 두 주파수 필요, 간격 2,000Hz. 사용 가능 대역 = 6,000-2,000=4,000Hz. 보오율=4,000baud. 2진FSK: 1비트/baud → 비트율=4,000bps.

  4. 4번궤환에 의한 발진회로에서 증폭기 이득 A, 궤환율 β일 때 발진이 지속되기 위한 조건은?

    1. ① βA = 1
    2. ② βA < 1
    3. ③ βA < 0
    4. ④ βA = 0

    정답 ① — 발진 지속 조건: βA = 1 (바르크하우젠 기준). βA > 1: 진폭 증가(클리핑), βA < 1: 발진 소멸.

  5. 5번다음 논리도에서 A, B, C, D 입력과 S1, S2 선택신호를 가진 회로는?

    1. ① 멀티플렉서(multiplexer)
    2. ② 디멀티플렉서(demultiplexer)
    3. ③ 인코더(encoder)
    4. ④ 디코더(decoder)

    정답 ① — 멀티플렉서: 여러 입력(A,B,C,D)을 선택신호(S1,S2)에 따라 하나의 출력으로 선택. 4:1 MUX.

  6. 6번UTP(Unshielded Twisted-Pair) 케이블에 대한 설명으로 옳은 것은?

    1. ① CAT.6 케이블 규격은 100BASE-TX이다
    2. ② CAT.5E 케이블의 대역폭은 500[MHz]이다
    3. ③ CAT.3 케이블은 최대 1[Gbps] 전송속도를 지원한다
    4. ④ CAT.7 케이블은 최대 10[Gbps] 전송속도를 지원한다

    정답 ④ — CAT.7: 10Gbps, 600MHz. CAT.6=1Gbps/250MHz, CAT.5E=1Gbps/100MHz, CAT.3=10Mbps/16MHz.

  7. 7번선로의 전송특성 열화 요인에서 정상열화요인이 아닌 것은?

    1. ① 펄스성 잡음
    2. ② 위상 지터
    3. ③ 반향
    4. ④ 누화

    정답 ① — 정상열화요인: 위상 지터, 반향(에코), 누화(크로스토크), 주파수 편이, 지연왜곡. 펄스성 잡음은 우발적(비정상) 열화요인.

  8. 8번다중모드 광섬유(Multimode Fiber)에 대한 설명으로 틀린 것은?

    1. ① 코어내를 전파하는 모드가 여러 개 존재한다
    2. ② 모드간 간섭이 있어 전송대역이 제한된다
    3. ③ 고속, 대용량 장거리 전송에 사용된다
    4. ④ 단일모드 광섬유보다 제조 및 접속이 용이하다

    정답 ③ — 다중모드 광섬유: 모드 분산으로 대역폭 제한 → 단거리용. 장거리 고속 대용량은 단일모드(Single Mode) 광섬유 사용.

  9. 9번주파수가 2[GHz]인 전파의 파장은?

    1. ① 5[cm]
    2. ② 10[cm]
    3. ③ 15[cm]
    4. ④ 20[cm]

    정답 ③ — λ = c/f = 3×10⁸ / (2×10⁹) = 0.15[m] = 15[cm]

  10. 10번밀리미터파의 특징으로 틀린 것은?

    1. ① 저전력 사용
    2. ② 우수한 지향성
    3. ③ 낮은 강우 감쇠
    4. ④ 송수신장치의 소형화

    정답 ③ — 밀리미터파(30~300GHz): 강우 감쇠가 크다(높음). 파장이 짧아 빗방울의 산란 영향이 큼. 낮은 강우 감쇠는 틀린 설명.

  11. 11번신호전압 25[V], 잡음전압 0.0025[V]일 때 신호대잡음비(SNR)는 몇 [dB]인가?

    1. ① 40[dB]
    2. ② 60[dB]
    3. ③ 80[dB]
    4. ④ 100[dB]

    정답 ③ — SNR[dB] = 20×log(V_s/V_n) = 20×log(25/0.0025) = 20×log(10,000) = 20×4 = 80[dB]

  12. 12번정보 전송률 R과 채널용량 C간의 관계가 옳은 것은?

    1. ① R<C 이면, 채널부호를 이용해 에러율을 임의로 작게 할 수 있다
    2. ② R<C 이면, 모뎀을 이용해 에러율을 임의로 작게 할 수 있다
    3. ③ R>C 이면, 채널부호를 이용해 에러율을 임의로 작게 할 수 있다
    4. ④ R>C 이면, 모뎀을 이용해 에러율을 임의로 작게 할 수 있다

    정답 ① — 샤논의 채널 코딩 정리: R<C 이면 채널부호화를 통해 에러율을 임의로 0에 가깝게 할 수 있음. R>C이면 에러 없는 전송 불가.

  13. 13번동일한 데이터를 2회 송출하여 수신 측에서 비교 체크함으로써 에러를 검출하는 방식은?

    1. ① 반송제어 방식
    2. ② 연속송출 방식
    3. ③ 캐릭터 패리티 검사 방식
    4. ④ 사이클릭 부호 방식

    정답 ② — 연속송출(반복) 방식: 동일 데이터를 2회 이상 반복 전송하고 수신 측에서 비교하여 에러 검출. 단순하지만 전송 효율 낮음.

  14. 14번동기식 전송방식에 대한 설명으로 옳은 것은?

    1. ① 각 글자는 시작 비트와 정지 비트를 갖는다
    2. ② 데이터의 앞쪽에 반드시 비동기문자가 온다
    3. ③ 한 묶음으로 구성하는 글자들 사이에는 휴지기간이 있을 수 있다
    4. ④ 회선의 효율을 증가시키기 위해 블록 단위로 송수신한다

    정답 ④ — 동기식 전송: 블록(프레임) 단위로 전송, 글자 사이 휴지 없음, 동기문자(SYN) 사용. 시작/정지 비트는 비동기식 특징.

  15. 15번TDM(Time Division Multiplexing) 수신기에 대한 설명으로 틀린 것은?

    1. ① 수신기에서 표본기(Decommutator)는 수신되는 신호와 비동기식으로 동작한다
    2. ② 저역통과필터(LPF)는 PAM 샘플로부터 아날로그 신호를 재구성하는데 사용된다
    3. ③ LPF가 불량하면 심볼 간 간섭이 발생할 수 있다
    4. ④ 한 신호가 다른 채널에 나타나는 Crosstalk 현상이 발생할 수 있다

    정답 ① — TDM 수신기의 표본기(Decommutator)는 송신기와 동기(Synchronous)로 동작해야 함. 비동기식 동작은 틀린 설명.

  16. 16번PDH 및 SDH/SONET의 공통점이 아닌 것은?

    1. ① 디지털 다중화에 의한 계위 신호 체계
    2. ② 시분할 다중화(TDM)방식
    3. ③ 프레임 반복 주기는 125us
    4. ④ 북미 표준의 동기식 다중화 방식 디지털 계위 신호 체계

    정답 ④ — PDH는 북미(T-Carrier)와 유럽(E-Carrier) 표준. SDH/SONET은 국제 표준. "북미 표준의 동기식 다중화"는 SONET만의 특징.

  17. 17번광대역종합정보통신망(B-ISDN)에 대한 설명으로 틀린 것은?

    1. ① ATM방식
    2. ② 회선교환방식
    3. ③ 광전송 기술
    4. ④ 양방향 통신

    정답 ② — B-ISDN은 ATM(비동기전송모드) 패킷교환 방식 사용. 회선교환방식은 PSTN(기존 전화망)의 방식.

  18. 18번주파수도약 대역확산(FHSS) 방식의 특징이 아닌 것은?

    1. ① 직접확산방식에 비해 가입자 수용 용량이 작다
    2. ② 동기화가 필요없다
    3. ③ 여러개의 반송파를 사용한다
