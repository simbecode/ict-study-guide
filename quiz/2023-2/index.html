2023년 2회 필기 기출 100문항 전체와 해설입니다. 과목별로 묶었고, 정답 보기는 초록색으로 표시했습니다. 직접 풀어 보려면 기출문제 풀이 모드를 이용하세요.

100문항5과목해설 포함

1과목 정보전송일반

  1. 1번어떤 신호가 4개의 데이터 준위를 가지며 펄스시간은 1[ms]일 때 비트 전송률은?

    1. ① 1,000[bps]
    2. ② 2,000[bps]
    3. ③ 4,000[bps]
    4. ④ 8,000[bps]

    정답 ② — 비트전송률 = 보오율 × log₂M = (1/0.001) × log₂4 = 1,000 × 2 = 2,000[bps]

  2. 2번데이터의 신호처리 과정에서 나타나는 엘리어싱(Aliasing) 현상에 대한 설명으로 틀린 것은?

    1. ① 표본화율이 나이키스트 표본화율보다 낮으면 발생한다
    2. ② 엘리어싱이 발생하면 원래의 신호를 정확히 재생하기 어렵다
    3. ③ 표본화 전에 HPF(High Pass Filter)를 사용하여 엘리어싱을 방지할 수 있다
    4. ④ 주파수스펙트럼 분포에서 서로 이웃하는 부분이 겹쳐서 발생한다

    정답 ③ — 엘리어싱 방지에는 LPF(Low Pass Filter, 저역통과필터) 사용. HPF는 고주파 통과 필터로 엘리어싱 방지에 사용되지 않음.

  3. 3번2비트 데이터 크기를 4준위 신호 중 하나에 속하는 2비트 패턴의 1개 신호 요소로 부호화하는 회선 부호화(Line Coding) 방식은?

    1. ① RZ(Return to Zero)
    2. ② NRZ-I(Non Return to Zero - Inverted)
    3. ③ 2B/1Q
    4. ④ Differential manchester

    정답 ③ — 2B/1Q(2 Binary, 1 Quaternary): 2비트를 4준위(Quaternary) 신호 1개로 매핑. ISDN BRI에서 사용.

  4. 4번회로에서 입력 A, B, C와 AND/OR/NOT 게이트로 구성된 출력 X에 대한 부울식은?

    1. ① X = Ā+B+C
    2. ② X = B+ĀC
    3. ③ X = A+B̄C
    4. ④ X = A+B+C̄

    정답 ④ — 이미지 기반 논리 회로 문제. 정답은 X = A+B+C̄ (NOT C가 포함된 OR 게이트 조합).

  5. 5번A, B 두 입력과 X(차), Y(빌림) 두 출력을 가지는 다음 그림의 회로 명칭은?

    1. ① 가산기
    2. ② 감산기
    3. ③ 반감산기
    4. ④ 비교기

    정답 ③ — 반감산기(Half Subtractor): 두 1비트를 빼는 회로. 출력: 차(Difference)=A⊕B, 빌림(Borrow)=ĀB. 입력은 2개, 출력은 2개.

  6. 6번통신용 중계케이블의 통화전압이 55[V]이고 잡음전압이 0.055[V]이면 잡음레벨[dB]은?

    1. ① 44[dB]
    2. ② 50[dB]
    3. ③ 55[dB]
    4. ④ 60[dB]

    정답 ④ — 잡음레벨[dB] = 20×log(V신호/V잡음) = 20×log(55/0.055) = 20×log(1000) = 20×3 = 60[dB]

  7. 7번UTP 케이블 규격에 대한 설명으로 틀린 것은?

    1. ① CAT.5 케이블의 규격은 10BASE-T이다
    2. ② CAT.5E 케이블의 규격은 1000BASE-T이다
    3. ③ CAT.6 케이블의 규격은 1000BASE-TX이다
    4. ④ CAT.7 케이블의 규격은 10GBASE이다

    정답 ① — CAT.5 케이블 규격은 100BASE-TX(100Mbps), 10BASE-T는 CAT.3 규격. CAT.5E=1000BASE-T, CAT.6=1000BASE-TX, CAT.7=10GBASE.

  8. 8번광섬유 케이블에서 빛을 집광하는 능력, 즉 최대 수광각 범위 내로 입사시키기 위한 광학 렌즈의 척도를 무엇이라 하는가?

    1. ① 개구수(Numerical Aperture, NA)
    2. ② 조리개 값(F-number)
    3. ③ 분해거리(Resolved Distance)
    4. ④ 초점심도(Depth of Focus)

    정답 ① — 개구수(NA): 광섬유가 빛을 집광하는 능력. NA = n×sinθ. NA가 클수록 더 많은 빛을 집광. 광섬유 코어와 클래딩의 굴절률 차이로 결정.

  9. 9번인공위성이나 우주 비행체와 같이 매우 빠른 속도로 운동하는 경우 전파발진원의 이동에 따라서 수신주파수가 변하는 현상은?

    1. ① 페이저 현상
    2. ② 플라즈마 현상
    3. ③ 도플러 현상
    4. ④ 전파지연 현상

    정답 ③ — 도플러 현상(Doppler Effect): 발진원의 이동에 따라 수신 주파수가 변화. 발진원이 접근하면 주파수 증가, 멀어지면 감소.

  10. 10번무선통신시스템에서 송신출력이 10[W], 송수신 안테나 이득이 각각 25[dBi], 수신 전력이 -20[dBm]이라고 할 때 자유공간 손실은 몇 [dB]인가?

    1. ① 100 [dB]
    2. ② 105 [dB]
    3. ③ 110 [dB]
    4. ④ 115 [dB]

    정답 ③ — 10W = 40dBm. 자유공간손실 = Pt[dBm] + Gt[dB] + Gr[dB] - Pr[dBm] = 40 + 25 + 25 - (-20) = 110[dB]

  11. 11번비트율이 고정되어 있을 때 다원 베이스밴드 전송(Multilevel Baseband Transmission)을 사용하여 심볼당 비트 수를 증가시켜 전송한다면 어떠한 효과가 있는가?

    1. ① 전송 대역폭을 줄일 수 있다
    2. ② 전송 전력을 줄일 수 있다
    3. ③ 비트 에러율이 줄어든다
    4. ④ 얻어지는 효과가 없다

    정답 ① — 다원 전송: 심볼당 비트 수 증가(예: 4QAM→16QAM) → 같은 비트율에서 심볼 속도 감소 → 필요 대역폭 감소. 단, BER은 증가할 수 있음.

  12. 12번데이터 전송 시 서로 다른 전송 선로상의 신호가 정전 결합, 전자 결합 등 전기적 결합에 의하여 다른 회선에 영향을 주는 현상은?

    1. ① 왜곡(Distortion)
    2. ② 누화(Crosstalk)
    3. ③ 잡음(Noise)
    4. ④ 지터(Jitter)

    정답 ② — 누화(Crosstalk): 인접 전송 선로 간 전기적 결합(정전/전자)으로 신호가 다른 회선에 영향. 근단누화(NEXT), 원단누화(FEXT).

  13. 13번시분할 다중화(TDM)에 대한 설명으로 틀린 것은?

    1. ① 망동기가 필요하다
    2. ② 수신시 비트 및 프레임 동기가 필요하다
    3. ③ 인접채널간 간섭을 줄이기 위해 보호대역이 필요하다
    4. ④ 데이터 프레임 구성시 필요한 오버헤드가 커서 데이터 전송 효율이 떨어진다

    정답 ③ — 보호대역(Guard Band)은 FDM(주파수 분할 다중화)의 특징. TDM은 시간 슬롯 방식이므로 보호대역 불필요.

  14. 14번OFDM과 FDM을 비교한 설명으로 적합하지 않은 것은?

    1. ① OFDM과 FDM은 정보 전송을 위하여 주파수 대역을 나눈다는 공통점이 있다
    2. ② OFDM 방식에서는 직교성을 사용하여 FDM 방식보다 대역폭 효율이 좋지 않다
    3. ③ FDM 방식은 OFDM 방식과 동일하게 다중 부반송파를 사용한다
    4. ④ FDM 방식은 많은 수의 변복조기가 필요하다

    정답 ② — OFDM은 직교성(Orthogonality)을 이용해 부반송파 간격을 최소화 → FDM보다 대역폭 효율이 좋음. 반대 설명이 틀림.

  15. 15번신호레벨이 변하는 속도로 매초에 전송할 수 있는 부호의 수를 의미하며 하나의 부호(심볼)를 전송할 때 필요한 시간에 대한 심볼의 폭으로 나타낼 수 있으며 단위는 Baud인 것은?

    1. ① 변조속도
    2. ② 데이터 신호속도
    3. ③ 데이터 전송속도
    4. ④ 베어러(Bearer) 속도

    정답 ① — 변조속도(Baud Rate): 1초에 전송할 수 있는 심볼(부호)의 수. 단위는 Baud(보). 비트율[bps] = 변조속도[Baud] × log₂M.

  16. 16번FH(Frequency Hopping) 방식에 대한 설명으로 틀린 것은?

    1. ① 미리 정해진 순서(의사랜덤수열)에 따라 서로 다른 호핑용 채널에 할당시킨다
    2. ② 수신측은 송신 시 사용한 호핑 코드와 동일한 코드를 이용하여 특정 시간에 특정 주파수로 튜닝하여야 한다
    3. ③ 같은 주파수를 사용하더라도 호핑 코드만 다르면 여러 확산대역시스템을 동일 장소에 사용 가능하다
    4. ④ 동일 지역에서 서로 다른 도약 시퀀스(Hopping Sequence)에 의해 네트워크를 분리할 수 없다

    정답 ④ — FH 방식은 서로 다른 도약 시퀀스를 사용하면 동일 지역에서도 여러 네트워크를 독립적으로 분리 운용 가능.

  17. 17번이동통신에서 다중 경로의 반사파에 의해 발생되는 페이딩으로 페이딩 주기가 짧고, 도심지역에서 주로 발생하는 페이딩은?

    1. ① Long Term Fading
    2. ② 흡수성 Fading
    3. ③ Rician Fading
    4. ④ Short Term Fading

    정답 ④ — Short Term Fading(단기 페이딩): 다중 경로 반사파로 인한 빠른 페이딩. 도심지역에서 빈번. Rayleigh 또는 Rician 페이딩이 해당.

  18. 18번주기 신호가 300[Hz], 400[Hz], 500[Hz]의 주파수를 갖는 3개의 정현파로 분해될 경우 대역폭은?

    1. ① 200[Hz]
    2. ② 300[Hz]
    3. ③ 400[Hz]
