1과목 정보전송일반

  1. 1번스마트 안테나(Smart antenna) 종류가 아닌 것은?

    1. ① MIMO(Multiple Input Multiple Output antenna)
    2. ② Switched beam array antenna
    3. ③ Adaptive array antenna
    4. ④ SISO(Single Input Single Output antenna)

    정답 ④ — SISO는 단일 입출력 안테나로 스마트 안테나가 아님. 스마트 안테나: MIMO, 빔 전환 배열, 적응형 배열.

  2. 2번100[mV]는 몇 [dBmV]인가? (단, 1[mV]는 0[dBmV] 이다.)

    1. ① 10[dBmV]
    2. ② 20[dBmV]
    3. ③ 30[dBmV]
    4. ④ 40[dBmV]

    정답 ④ — dBmV = 20×log(V/1mV) = 20×log(100/1) = 20×log100 = 20×2 = 40[dBmV]

  3. 3번단파 통신에서 페이딩(fading)에 대한 경감법으로 적합하지 않은 것은?

    1. ① 간섭성 페이딩은 AGC 회로를 부가한다
    2. ② 편파성 페이딩은 편파다이버시티를 사용한다
    3. ③ 흡수성 페이딩은 수신기에 AGC 회로를 부가한다
    4. ④ 선택성 페이딩은 주파수 다이버시티 또는 SSB통신방식을 사용한다

    정답 ① — 간섭성 페이딩은 diversity(다이버시티) 기법으로 경감. AGC는 흡수성/K형 페이딩에 사용.

  4. 4번구내통신선로설비 기술기준에 대한 국제표준은?

    1. ① ISO/IEC 96000
    2. ② ISO/IEC 29103
    3. ③ ISO/IEC 11801
    4. ④ ISO 20022

    정답 ③ — ISO/IEC 11801: 구내통신 케이블링(정보기술 일반 케이블링) 국제 표준. UTP/광케이블 규격 정의.

  5. 5번PDH 북미방식 T1의 전송속도는?

    1. ① 64[Kbps]
    2. ② 1.544[Mbps]
    3. ③ 2.048[Mbps]
    4. ④ 6.312[Mbps]

    정답 ② — T1(북미): 1.544Mbps = 24채널×64Kbps. E1(유럽): 2.048Mbps = 32채널×64Kbps.

  6. 6번공통선 신호방식에서 사용되는 다중화 방식은?

    1. ① FDM
    2. ② TDM
    3. ③ CDM
    4. ④ WDM

    정답 ② — 공통선 신호방식(CCS): 별도 신호 전용채널로 신호정보를 TDM(시분할 다중화)으로 고속 전송.

  7. 7번문자방식 프로토콜에 사용되는 전송제어문자가 아닌 것은?

    1. ① ENQ
    2. ② DLE
    3. ③ REG
    4. ④ ETB

    정답 ③ — 전송제어문자: SOH, STX, ETX, EOT, ENQ, ACK, NAK, SYN, ETB, DLE 등. REG는 없는 문자.

  8. 8번전송로의 동적 불완전성 원인으로 발생하는 에러로 알맞은 것은?

    1. ① 지연 왜곡
    2. ② 에코
    3. ③ 손실
    4. ④ 주파수 편이

    정답 ② — 동적 불완전성: 에코, 페이딩, 위상 지터 등. 정적 불완전성: 지연 왜곡, 손실, 주파수 편이, 잡음 등.

  9. 9번전자 계산기의 기억 요소(Memory element)로 사용하는 장치가 아닌 것은?

    1. ① Disk
    2. ② REgister
    3. ③ Flip Flop
    4. ④ Inverter

    정답 ④ — 기억 요소: Disk, Register, Flip-Flop, RAM, ROM 등. Inverter(인버터)는 논리 게이트로 기억 기능 없음.

  10. 10번진폭 A인 구형파 신호의 실효값(rms)은?

    1. ① 0.5A
    2. ② A
    3. ③ 1.5A
    4. ④ 2A

    정답 ② — 구형파(Square wave)의 실효값 = 진폭 A. 정현파의 실효값 = A/√2 ≈ 0.707A와 구분.

  11. 11번전자파(전파)에 대한 설명으로 틀린 것은?

    1. ① 전자파를 파장이 짧은 것부터 나열하면 감마선, x선, 적외선 등이 있다
    2. ② 전자파는 파장이 짧을수록 직진성 및 지향성이 강하다
    3. ③ 전자파는 진공 또는 물질 속을 전자장의 진동이 전파함으로써 전자 에너지를 운반하는 것이다
    4. ④ 전파는 인공적인 유도에 의해 공간에 퍼져나가는 파이다

    정답 ④ — 전파는 자연적으로도 발생. 인공 유도만이 아님. 전파법상 전파는 인공적 전기회로에서 발생하는 전자파.

  12. 12번정보를 유지하기 위한 래치(Latch)회로나 시프트 레지스터(Shift register)에 주로 사용되는 플립플롭은?

    1. ① D Flip-Flop
    2. ② T Flip-Flop
    3. ③ RS Flip-Flop
    4. ④ K Flip-Flop

    정답 ① — D Flip-Flop: 데이터를 그대로 기억. 래치, 시프트 레지스터에 사용. D 입력값이 클럭에 의해 Q에 전달.

  13. 13번광섬유 케이블의 분류 방법이 다른 것은?

    1. ① 단일 모드 광섬유 파이버
    2. ② 계단형 광섬유 파이버
    3. ③ 언덕형 광섬유 파이버
    4. ④ 삼각형 광섬유 파이버

    정답 ① — 단일/다중 모드: 전파 모드 수에 의한 분류. 계단형/언덕형/삼각형: 굴절률 분포에 의한 분류. 분류 기준이 다름.

  14. 14번MIMO 안테나의 핵심기술이 아닌 것은?

    1. ① 핸드오버(Handover)
    2. ② 공간다중화(Spatial Multiplexing)
    3. ③ 다이버시티(Diversity)
    4. ④ 사전코딩(Pre-coding)

    정답 ① — MIMO 핵심기술: 공간다중화, 다이버시티, 빔포밍, 사전코딩. 핸드오버는 이동통신 기능으로 MIMO와 무관.

  15. 15번대류권파의 페이딩이 아닌 것은?

    1. ① 신틸레이션 페이딩
    2. ② K형 페이딩
    3. ③ 덕트형 페이딩
    4. ④ 도약성 페이딩

    정답 ④ — 대류권파 페이딩: 신틸레이션, K형, 덕트형, 산란형. 도약성(스킵) 페이딩은 전리층 반사에 의한 현상.

  16. 16번UWB(Ultra Wide Band) 방식의 설명으로 옳은 것을 모두 선택한 것은? (ㄱ.PPM 변조 단거리 무선, ㄴ.송신기 제작 쉽고 저렴, ㄷ.대용량 저전력, ㄹ.반송파 미사용 기저대역 전송)

    1. ① ㄱ
    2. ② ㄱ, ㄴ
    3. ③ ㄱ, ㄴ, ㄷ
    4. ④ ㄱ, ㄴ, ㄷ, ㄹ

    정답 ③ — UWB: ㄱ~ㄷ 모두 해당. ㄹ은 부분적 맞으나 수 GHz 이상 광대역 사용으로 엄밀히 기저대역 아님.

  17. 17번5단 귀환 시프트 레지스터(Shift Register)로 구성된 PN부호 발생기의 출력 데이터 계열의 주기는?

    1. ① 5
    2. ② 16
    3. ③ 31
    4. ④ 32

    정답 ③ — PN 부호(m-sequence) 주기 = 2ⁿ-1 = 2⁵-1 = 32-1 = 31. n=단 수.

  18. 18번LTE의 상향링크 전송방식으로, 여러 개의 주파수가 섞여 하나의 주파수로 보이며, 통화자들이 전체 부반송파켓수를 나누어 사용하는 방식은?

    1. ① OFDMA
    2. ② CDMA
    3. ③ FDMA
    4. ④ SC-FDMA

    정답 ④ — SC-FDMA(Single Carrier FDMA): LTE 상향링크 전송방식. PAPR 낮아 단말 전력증폭기 부담 개선.

  19. 19번12비트의 정보가 6ms마다 전송된다면 비트율[bps]은?

    1. ① 1000[bps]
    2. ② 1500[bps]
    3. ③ 2000[bps]
    4. ④ 2500[bps]

    정답 ③ — 비트율 = 12bit / 0.006s = 2,000[bps]

  20. 20번10,000,000개의 비트 중 2개가 오류일 때 비트 에러율은?

    1. ① 1×10⁻⁶
    2. ② 1×10⁻⁷
    3. ③ 2×10⁻⁶
    4. ④ 2×10⁻⁷

    정답 ④ — BER = 2/10,000,000 = 2×10⁻⁷
