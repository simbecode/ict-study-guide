⏱️ 공장가동률 — MTTF · MTTR · MTBF

공장 설비가 정상 가동과 고장 수리를 반복할 때의 가동률(가용도)을 정리합니다.
시스템이 얼마나 오래 잘 버티는가(MTTF), 고장 나면 얼마나 빨리 고치는가(MTTR), 수리 가능한 시스템이 고장 사이에 정상 가동한 평균 시간(MTBF)을 구분한다. 가동과 수리만 반복하는 시스템의 가동률(가용도)은 MTBF와 MTTR로 계산한다.
📌 세 용어 구분
MTTF
Mean Time To Failure
평균 고장 시간
정상 동작을 시작해서 고장 날 때까지의 평균 시간
주로 수리하지 않고 교체하는 부품의 평균 수명에 사용
MTTR
Mean Time To Repair
평균 수리 시간
고장 난 순간부터 복구 완료까지의 평균 시간
= 멈춰 있던 시간
MTBF
Mean Time Between Failures
평균 고장 간격
수리 가능한 시스템의 고장 사이 정상 가동 시간의 평균
= 정상 가동 시간 합고장 횟수 (수리 시간 제외)
🔗 핵심 관계식
MTBF 계산 기준
MTBF = 정상 가동 시간 합고장 횟수
가동 100 h + 90 h + 80 h, 고장 3회 → MTBF = 90 h
📈 시간축으로 보면
가동 100 h → 고장 → 수리 4 h → 가동 90 h → 고장 → 수리 3 h → 가동 80 h → 고장 MTBF = 100 + 90 + 803 = 90 h MTTR = 4 + 32 = 3.5 h (완료된 수리 2회 기준) MTBF ↑ (고장이 드물다) · MTTR ↓ (빨리 고친다) → 가동률 ↑
🎯 가동률(가용도, Availability) 공식
시험에 나오는 형태 — 이것만 외우면 된다
가동률 = MTBFMTBF + MTTR
불가동률 = MTTRMTBF + MTTR = 1 − 가동률
MTBF의 시간 기준을 확인하세요. 이 자료와 계산기는 MTBF를 수리 시간을 제외한 평균 정상 가동 시간으로 사용합니다. 가동과 수리만 반복하는 시스템의 장기 가용도는 MTBFMTBF + MTTR입니다. 수리 시간을 포함한 전체 주기를 고장 간격이라고 부르는 자료와 혼용하지 마세요. MTTF는 주로 비수리 부품의 평균 수명에 쓰며, 여기서 MTBF − MTTR로 계산하지 않습니다. NIST · MTBF 계산 기준 ↗
📖 기출 계산 예제

예제 1 2022-1회

Q: MTBF = 22시간, MTTR = 2시간 일 때 가동률은?

= 2222 + 2
= 2224
= 0.9166…
→ 0.92

예제 2 2023-2회

Q: 평균고장간격 23시간, 평균복구시간 1시간 일 때 1일 가동률[%]은?

= 2323 + 1
= 2324
= 0.9583…
→ 95.83 [%]

💡 분모는 MTBF + MTTR입니다. 두 예제는 합이 24시간이지만, 분모가 항상 24인 것은 아닙니다. 같은 시간 단위로 맞추고, 백분율을 구할 때는 100을 곱합니다.
🏭 공장 설비에 적용하기

연습 예제 — 정상 가동 180시간, 수리 20시간

관측 기간에 고장과 수리가 각각 4회 완료되었고, 정상 가동과 수리만 반복했다고 가정합니다.

MTBF = 1804 = 45시간
MTTR = 204 = 5시간
가동률 = 4545 + 5 = 0.9 = 90%
불가동률 = 1 − 0.9 = 10%

📝 꼭 외울 시험 포인트
• MTTF: 고장 날 때까지의 평균 시간 — 주로 비수리 부품의 수명
• MTBF: 정상 가동 시간 합고장 횟수 — 수리 시간 제외
• MTTR: 수리 시간 합완료된 수리 횟수
• 가동률 = MTBFMTBF + MTTR
• 불가동률 = MTTRMTBF + MTTR = 1 − 가동률
• MTBF는 길수록, MTTR은 짧을수록 가동률이 높다.
• 연간 정지 시간 = 8,760 × (1 − 가동률) [시간] — 365일·24시간 운용 기준, 가동률은 소수로 대입
