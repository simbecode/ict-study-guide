📡 전파 주파수 대역 — 마이크로파 밴드 구분

전파는 주파수가 높아질수록 파장이 짧아지고, 성질이 완전히 달라진다. 낮은 주파수는 멀리 돌아가고, 높은 주파수는 직진하며 많은 정보를 싣는다. 이 성질 차이 때문에 대역마다 쓰임새가 정해져 있다.
모든 계산의 출발점
λ = cf

🧭 먼저 감 잡기 — 주파수를 왜 나누는가
전파는 하나의 연속된 띠다. 그런데 주파수에 따라 성격이 완전히 달라진다. 낮은 주파수 (왼쪽) 높은 주파수 (오른쪽) ───────────────── ───────────────── 파장이 길다 (km 단위) 파장이 짧다 (mm 단위) 장애물을 돌아간다 (회절) 장애물에 막힌다 (직진) 멀리 간다 가까이만 간다 한 번에 적은 데이터 한 번에 많은 데이터 안테나가 크다 안테나가 작다 비·대기 영향 거의 없음 비·대기에 잘 흡수됨 그래서 용도가 정해진다. 잠수함·먼바다 → 낮은 주파수 (멀리 가야 하니까) 휴대폰·Wi-Fi → 중간 (적당히 가고 데이터도 실어야 하니까) 위성·5G → 높은 주파수 (데이터를 많이 실어야 하니까, 대신 비 오면 약함)
딱 한 문장으로 — "주파수를 올리면 속도는 얻고 거리는 잃는다." 이 맞바꿈 하나만 잡고 있으면 아래 표들이 전부 자연스럽게 읽힌다. 대역마다 쓰임새가 다른 이유도, 5G 밀리미터파가 기지국을 촘촘히 세워야 하는 이유도 전부 여기서 나온다.
⚠ 마이크로파의 범위 — 정의가 두 가지다
· 시험 표준 : 300 MHz ~ 30 GHz (UHF 일부 + SHF) — 정보통신기사에서는 이쪽으로 출제된다
· 광의의 정의 : 300 MHz ~ 300 GHz (EHF/밀리미터파까지 포함) — 일부 자료·인포그래픽이 이렇게 쓴다
혼동을 피하려면 "마이크로파의 상한은 30GHz, 그 위 30~300GHz는 밀리미터파(EHF)" 로 기억하는 것이 안전하다.

⚠ 전파의 법적 정의 — 전파법·ITU 모두 "인공적인 유도 없이 공간에 퍼져 나가는 3,000 GHz(3 THz) 이하의 전자파" 를 전파로 규정한다. 즉 위 그림의 전파 + THF 구간까지가 법적으로 전파이고, 적외선부터는 전파가 아니다.
📖 여기서 이어지는 것 — 광통신이 쓰는 850 · 1310 · 1550 nm는 가시광선이 아니라 적외선 영역이다. 눈에 보이지 않으므로 광섬유 작업 시 절대 단면을 들여다보면 안 된다. 1310nm는 분산 최소, 1550nm는 손실 최소 라는 점이 자주 출제된다.
이 그림에서 바로 읽히는 것 — ① 마이크로파 = UHF 뒷부분 + SHF (300MHz~30GHz) · ② Ku가 K보다 왼쪽(낮은 주파수) · ③ 위성 3쌍은 C(4/6) → Ku(12/14) → Ka(20/30) 순으로 오른쪽으로 이동 · ④ 오른쪽으로 갈수록 흡수·강우 감쇠 표시가 늘어난다 · ⑤ 마이크로파의 시험 기준 상한은 30GHz — Ka 밴드 중간에서 끊기고, 그 위 V·W는 밀리미터파 영역이다 · ⑤ 전자기파 전체로 보면 전파는 가장 낮은 끝, 그 위로 적외선 → 가시광선 → 자외선 → X선 → 감마선

⭐ 마이크로파(Microwave) 밴드 구분 — IEEE 표준
마이크로파 는 통상 300 MHz ~ 30 GHz (UHF 일부 + SHF)를 가리킨다. 파장이 1m ~ 1cm 로 짧아 파라볼라 안테나로 좁게 쏘아 보낼 수 있고, 대역폭이 넓어 대용량 전송이 가능하다. 이 영역을 다시 L · S · C · X · Ku · K · Ka · V · W 로 잘게 나눈 것이 밴드(Band) 다.

🧠 밴드 암기 장치 — 숫자를 외우지 말고 규칙을 외운다
① 순서 — 알파벳 넷 + K 삼형제
L · S · C · X  |  Ku · K · Ka  ( V · W )
앞 넷 L S C X 는 그냥 알파벳 넷, 뒤 셋은 전부 K 로 시작하는 K 삼형제 다. 헷갈리는 건 삼형제 순서뿐인데 — Ku = K-under, 즉 K 아래라는 뜻이다. u(under)는 아래, a는 위 → Ku → K → Ka. 끝.
② 경계 숫자 — ×2 를 세 번, 그다음 ×1.5 를 네 번
L S C X Ku K Ka 1 ─── 2 ─── 4 ─── 8 ─── 12 ─── 18 ─── 27 ─── 40 [GHz] ×2 ×2 ×2 ×1.5 ×1.5 ×1.5 ×1.5
경계 8개(1·2·4·8·12·18·27·40)를 통째로 외울 필요가 없다. 1에서 시작해 ×2 를 세 번 → 1·2·4·8, 거기서 ×1.5 를 네 번 → 12·18·27·40(40.5≈40). 경계가 곧 밴드의 시작이므로 이 사슬 하나로 L~Ka 일곱 밴드의 주파수 범위가 전부 복원된다. 꺾이는 지점은 8 GHz, 즉 X 밴드부터 증가율이 완만해진다고 기억한다.
③ 용도 — 밴드마다 장면 하나씩
L1~2GPS — 가장 낮고 가장 튼튼한 밴드. 비·구름에도 끊기면 안 되는 위치정보가 여기 산다.
S2~4집 안의 주파수 — Wi-Fi 2.4G · 블루투스 · 전자레인지(2.45GHz). 물을 데우는 주파수가 곧 집안 주파수다.
C4~8비에 강한 위성 (하향 4 / 상향 6). 열대·강우 지역용. 대신 접시가 크다.
X8~12군용 레이더 — X = 표적에 찍는 X 표시. 해상도가 좋아 레이더용.
Ku12~18위성방송 (12 / 14). 접시 60cm 로 작아졌지만 비 오면 TV가 끊긴다.
K18~27버려진 밴드 — 한복판 22.2GHz 에서 수증기가 흡수해 버린다. 그래서 아래(Ku)와 위(Ka)만 쓴다.
Ka27~405G mmWave 28GHz · 고속 위성(20 / 30). 가장 빠르고 가장 비에 약하다.
한 문장으로 — "GPS → 집 → 비에 강한 위성 → 군용 레이더 → 위성방송 → 물에 막힘 → 5G"
④ 위성 3쌍 — 하향 / 상향
C 4 / 6  →  Ku 12 / 14  →  Ka 20 / 30
항상 상향(Up) > 하향(Down) — "올려 보낼 때 더 세게(높게) 쏜다" 로 외운다. 지구국은 전력이 넉넉하니 높은 주파수를 쓰고, 위성은 전력이 부족하니 감쇠가 적은 낮은 주파수를 내려보낸다.
⑤ 대기 흡수 두 구덩이
물 22  ·  공기 60
22.2GHz = 수증기(H₂O) 흡수 → K 밴드를 못 쓰는 이유. 60GHz = 산소(O₂) 흡수 → V 밴드가 근거리 전용인 이유. "물 이십이, 공기 육십" 다섯 글자면 K와 V 의 성격이 동시에 설명된다.
정리 — 순서는 「알파벳 넷 + K삼형제(u는 아래)」, 숫자는 「1에서 2배 세 번, 8에서 1.5배 네 번」, 용도는 「GPS→집→위성→레이더→방송→물막힘→5G」. 이 세 줄이면 표 전체가 복원된다.

📶 마이크로파 통신방식의 특징

✅ 장점

• 광대역 전송 가능 (대용량)
• 파장이 짧아 고이득 · 지향성 안테나(파라볼라) 사용
• 안테나가 작아 설치가 쉬움
• 외부 잡음(공전·인공잡음) 영향이 적음
• S/N이 양호하고 통신 품질이 안정적
• 회선 구성이 유선보다 빠르고 저렴

⚠ 단점

• 직진성이 강해 가시선(LOS) 이 필요 → 약 50km마다 중계소
• 산·건물 등 장애물에 차단됨
• 10GHz 이상에서 강우 감쇠 급증
• 다중경로에 의한 페이딩 발생
• 주파수 자원 확보(면허) 필요

⚠ 기출 함정 — "마이크로파 통신은 외부의 영향을 많이 받지만 광대역성이 가능하다" → 틀림. 마이크로파는 외부 잡음의 영향이 적은 것이 장점이다.

📡 등방성 안테나 · 전계강도 계산

📐 전계강도
E = √(30·P)d
E : 전계강도 [V/m]
P : 방사전력 [W]
d : 거리 [m]
📐 전력 밀도
S = P4πd²
S : 전력 밀도 [W/m²]
P : 방사전력 [W]
d : 거리 [m]
🔗 공식 유도 흐름
1
등방성 안테나는 모든 방향으로 균일하게 전파 방사
→ 거리 d에서 구면적 = 4πd²
2
전력 밀도 S = P4πd²
전계강도와의 관계: S = E²120π (자유공간 임피던스 Z₀ = 120π ≈ 377Ω)
3
E²120π = P4πd²
E² = 120π × P4πd² = 30Pd²
∴ E = √(30P)d
📉 자유공간 경로 손실 (Free Space Path Loss)
자유공간 손실 공식
L[dB] = 20log4πdλ
= 20log(d) + 20log(f) + 상수
실용식: L[dB] ≈ 32.44 + 20log(d[km]) + 20log(f[MHz])
관련 공식 전체 정리
전계강도 E = √(30·P)d [V/m]
전력 밀도 S = P4πd² [W/m²]
E·S 관계 S = E²120π (∵ Z₀ = 377Ω)
수신 전력 Pr = Pt·Gt·Gr·(λ4πd)²
자유공간 손실 L = (4πdλ)² = (4πdfc)²
손실[dB] 20log4πdλ ≈ 32.44 + 20log(d[km]) + 20log(f[MHz])

📐 FM 핵심 공식 — 변조지수와 카슨의 법칙
카슨의 법칙 (Carson's Rule)
BW = 2(Δf + fm) = 2fm(mf + 1)
변조지수 mf = Δffm
Δf : 최대 주파수 편이 [Hz]  ·  fm : 신호 최고 주파수 [Hz]
FM 라디오 예) Δf = 75[kHz], fm = 15[kHz] → mf = 5, BW = 2(75+15) = 180[kHz]
FM은 왜 잡음에 강한가 — 정보가 주파수 에 실려 있고 진폭은 항상 일정하기 때문에, 진폭에 실려 들어온 잡음을 리미터(Limiter) 로 잘라내도 정보가 손상되지 않는다. 대신 대역폭을 AM보다 훨씬 넓게 쓴다(FM 수백 kHz vs AM 약 10 kHz) — 대역폭을 희생해 S/N을 얻는 교환 관계.

💠 디지털 변조 — ASK / FSK / PSK

디지털 데이터(0과 1)를 아날로그 전송로로 보내기 위해 반송파의 진폭 · 주파수 · 위상 중 무엇을 바꾸느냐로 ASK · FSK · PSK가 나뉜다. 진폭과 위상을 동시에 바꾸면 QAM이 된다.
🎯 3대 방식 비교
방식변화 요소잡음 내성대역 효율검파특징 / 용도
ASK
Amplitude Shift Keying		 진폭 (있음/없음 = OOK) 가장 약함 보통 동기 · 비동기 모두 회로가 가장 간단하고 저렴. 진폭에 정보가 있어 잡음 · 페이딩에 취약. 광통신(빛 On/Off), 저속 회선
FSK
Frequency Shift Keying		 주파수 (2개 이상) 강함 낮음 동기 · 비동기 모두 구현이 쉽고 잡음에 강하지만 주파수를 여러 개 쓰므로 대역폭을 많이 차지. 1200[bps] 이하 저속 모뎀, 무선호출
PSK
Phase Shift Keying		 위상 강함 높음 동기 검파만 같은 대역에서 더 많은 비트 전송 가능. 위상 기준이 필요해 수신기가 복잡. 중·고속 모뎀, 위성통신
잡음 내성  PSK ≥ FSK > ASK   |   대역 효율  QAM > PSK > ASK > FSK
회로 간단한 순  ASK > FSK > PSK > QAM

비트율 · 변조속도 관계
비트율[bps] = 변조속도[baud] × n

📖 기출 예제 — 전송매체의 대역폭이 12,000[Hz], 두 반송파 주파수 사이의 간격이 최소 2,000[Hz] 일 때 2진 FSK 신호의 보오율과 비트율은? 전이중 · 각 방향 동일 대역폭
① 전이중(Full-Duplex) 이므로 대역을 반으로 나눠 쓴다
순방향 (송신)6,000 Hz
역방향 (수신)6,000 Hz
전체 12,000 Hz 를 반씩. 양방향이 동시에 흐르므로 각자 자기 대역이 필요하다.
② 한 방향 6,000 Hz 안에 반송파 두 개를 세운다
f₁0 을 표현
f₂1 을 표현
◀ 간격 2,000 Hz ▶
◀ 한 방향 대역폭 6,000 Hz ▶
FSK는 0과 1을 서로 다른 주파수 두 개로 보낸다. 두 반송파가 서로 간섭하지 않으려면 최소 2,000 Hz 는 떨어져 있어야 한다.
③ 그래서 신호가 실제로 쓸 수 있는 폭이 정해진다
한 방향 대역폭 = 보오율 + 반송파 간격
6,000 = 보오율 + 2,000   →   보오율 = 4,000 [baud]
④ 2진(M = 2) 이므로 심볼 하나에 1비트
n = log₂M = log₂2 = 1
비트율 = 4,000 × 1 = 4,000 [bps]
정답
보오율 4,000 [baud]  ·  비트율 4,000 [bps]
2진이므로 n = 1 → 보오율 = 비트율
⚠ 두 군데서 틀린다
① 「전이중」을 놓치는 경우 — 12,000을 그대로 쓰면 12,000 − 2,000 = 10,000 baud 라는 오답이 나온다. 문제에 전이중 · 양방향 · 동시 송수신 이라는 말이 있으면 제일 먼저 2로 나눈다. (단방향·반이중이면 나누지 않는다.)
② 반송파 간격 빼는 것을 잊는 경우 — 6,000을 그대로 보오율로 쓰면 안 된다. FSK는 주파수 두 개를 써야 하므로 둘을 떼어 놓는 몫(2,000 Hz)을 대역에서 먼저 떼어낸다.
💡 한 줄 절차 — 「전이중이면 ÷2 → 간격 빼기 → 그게 보오율 → ×log₂M 하면 비트율」. 이 순서 하나로 ASK·FSK·PSK 대역폭 문제가 전부 풀린다. 2진이면 log₂2 = 1 이라 마지막 단계에서 숫자가 그대로 간다.

🌐 QAM / OFDM

📶 QAM — 직교 진폭 변조 (Quadrature Amplitude Modulation)
진폭(ASK)과 위상(PSK)을 동시에 변조해 하나의 심볼에 더 많은 비트를 싣는 방식. 90° 위상차를 갖는 두 반송파(I : cos, Q : sin)에 각각 데이터를 실어 합성하므로 "직교(Quadrature)" 라 부른다.
방식신호점 수 (M)심볼당 비트필요 SNR주 사용처
16QAM164 bit낮음LTE, Wi-Fi 기본
64QAM646 bit보통디지털 CATV, LTE
256QAM2568 bit높음DOCSIS 3.x, Wi-Fi 5
1024QAM102410 bit매우 높음Wi-Fi 6, 5G NR
진수를 올리면? — 심볼당 비트가 늘어 전송 속도는 빨라지지만, 성상도의 신호점 간 거리가 좁아져 잡음에 취약해지고 더 높은 S/N이 필요하다. 전송 속도와 잡음 내성은 교환 관계.
⚠ 기출 — QAM은 위상 기준이 필요하므로 동기 검파만 사용한다. "비동기 검파도 사용한다"는 설명은 틀림.
📡 OFDM — 직교 주파수 분할 다중화
고속의 데이터를 다수의 직교하는 협대역 부반송파(Subcarrier) 로 나누어 병렬 전송하는 방식. 각 부반송파는 저속이 되므로 심볼 주기가 길어져 다중경로 페이딩에 강해진다.
직교 조건 (Orthogonality)
Δf = 1Ts
부반송파 간격 Δf 가 심볼 주기 Ts 의 역수일 때, 각 부반송파의 스펙트럼 정점에서
다른 모든 부반송파의 값이 0 이 된다 → 스펙트럼이 겹쳐도 간섭 없음

✅ OFDM 장점

• 주파수 선택적 페이딩에 강함
• 보호대역 불필요 → 높은 대역 효율
• CP(Cyclic Prefix, 보호구간) 삽입으로 심볼 간 간섭(ISI) 방지
• IFFT/FFT로 구현 → 디지털 회로로 간단
• 부반송파별 적응 변조 가능

⚠ OFDM 단점

• PAPR(첨두전력 대 평균전력비)이 높음 → 전력증폭기 부담
• 주파수 오프셋 · 위상잡음에 민감 (동기 정밀도 요구)
• CP만큼 전송 효율 손실
• 도플러 천이에 취약

SC-FDMA — LTE 상향링크(단말 → 기지국) 전송 방식. OFDM의 높은 PAPR 문제를 개선해 단말 전력증폭기 부담을 줄인다. 하향링크는 OFDMA. 기출 단골

🔑 다중화(Multiplexing) vs 다원접속(Multiple Access)
· 다중화: 하나의 송신측이 여러 신호를 묶어 전송 (송신측 시점)

· 기술은 같지만 관점 차이: FDM → FDMA, TDM → TDMA, CDM → CDMA

🔄 궤환(Feedback) / 발진(Oscillation) 회로

궤환(Feedback)이란 증폭기의 출력 일부를 입력으로 되돌리는 동작.
궤환 방식에 따라 부궤환(안정성↑) 또는 정궤환(발진 발생)이 나타남.
🔀 부궤환(Negative) vs 정궤환(Positive)
부궤환 (Negative Feedback)
· 출력을 입력에서 빼서 되돌림 (180° 위상차)
· 폐루프 이득: Af = A1 + Aβ
· 이득은 ↓, 안정성·대역폭은 ↑
· 왜곡·잡음 ↓
· 용도: 증폭기 설계 (오디오·계측)
정궤환 (Positive Feedback)
· 출력을 입력에 더해서 되돌림 (동상)
· 폐루프 이득: Af = A1 − Aβ
· 분모 → 0 이면 이득 ∞ → 발진
· 용도: 발진기·슈미트 트리거
🧠 부호 암기 — 「이름과 분모 부호는 반대, 효과는 이름대로」
부(−)궤환 → 분모 1 + Aβ   |   정(+)궤환 → 분모 1 − Aβ
이름에 − 가 붙은 부궤환의 분모가 +, 이름에 + 가 붙은 정궤환의 분모가 − 다. 헷갈릴 때는 결과로 되짚는다 — 부궤환은 이득이 줄어야 하니 분모가 커져야 하고(1+Aβ), 정궤환은 이득이 늘다가 터져야 하니 분모가 작아져야 한다(1−Aβ). Aβ가 1에 닿는 순간 분모가 0 → 이득 ∞ → 발진.
⚡ 바크하우젠 발진 조건 (Barkhausen Criterion) — 최다 출제!
발진이 지속되기 위한 조건
진폭 조건
|Aβ| = 1
루프 이득 = 1
위상 조건
∠Aβ = 0°
(또는 360°·n × 360°, 동상)
루프 이득(Loop Gain) Aβ = 증폭기 이득(A) × 궤환율(β)
두 조건을 동시에 만족해야 안정적 발진이 지속됨
🧠 한 문장으로 — 「한 바퀴 돌아왔을 때 크기 그대로(×1), 위상 그대로(0°)」
발진은 자기가 자기를 계속 만들어내는 상태다. 신호가 증폭기 → 궤환회로를 한 바퀴 돌아 입력으로 돌아왔을 때, 크기가 줄지도 늘지도 않고(|Aβ|=1) 파형이 어긋나지도 않아야(∠Aβ=0°) 원래 신호를 그대로 대신할 수 있다. 그래서 조건이 「크기 1, 각도 0」 두 개뿐이다. 합·차·나눗셈 보기(A+β=1, A−β=1, A/β=1)는 전부 오답 — 루프를 돌면 곱해지기 때문에 반드시 곱(Aβ) 이다.
📊 Aβ 값에 따른 발진 거동
Aβ 값 발진 거동 출력 파형 실제 의미
Aβ > 1 진폭이 점점 커짐 클리핑·포화 발진 시작 단계 (과도 상태)
Aβ = 1 일정 진폭 유지 안정적 정현파 지속 발진 (이상적 상태)
Aβ < 1 진폭이 점점 작아짐 감쇠 → 소멸 발진 멈춤

🧠 발진회로 암기 장치
① 하틀리 vs 콜피츠 — 「C로 시작하면 C가 두 개」
Colpitts = Capacitor 두 개 (L · C₁ · C₂) — 머리글자가 같아 이것 하나만 외우면 된다.
나머지 하나인 Hartley 는 자동으로 코일(L) 두 개 (L₁ · L₂ · C). 탭(tap)이 어디에 달렸는지를 묻는 문제가 그대로 같은 이야기다 — 콜피츠는 커패시터에 탭, 하틀리는 코일에 탭.
② 클랩 · 암스트롱 — 나머지 둘은 「콜피츠 + C」와 「변압기」
클랩(Clapp) = 콜피츠에 C를 하나 더 직렬로 붙인 개량형 (C 세 개) → 주파수 안정도 ↑. "콜피츠에 하나 더 붙여 손뼉(clap) 친다" 정도로 묶어 두면 순서가 안 엉킨다.
암스트롱(Armstrong) = 혼자만 변압기(티클러 코일) 결합. LC 4형제 중 결합 방식이 다른 하나로 기억한다.
③ RC 두 개 — 「위상천이는 60°×3, 윈브리지는 오디오」
위상천이 발진기는 RC 3단이 각 60°씩 = 180°, 나머지 180°는 반전 증폭기가 담당해 합이 360°(=0°)가 된다. "RC가 반, 증폭기가 반" 으로 외우면 60°·3단·180° 숫자가 한꺼번에 따라온다.
윈 브리지는 오디오 대역의 저왜곡 정현파 — 저주파 쪽이 RC 담당이라는 큰 그림과 맞물린다.
④ 안정도 순위 — 「수 · L · R」
수정 > LC > RC — 값비싼 순서가 곧 안정한 순서다. 담당 주파수도 같은 줄에 붙는다: RC = 저주파(Hz~kHz), LC = 고주파(MHz~GHz), 수정 = 정밀·기준. LC를 저주파에 못 쓰는 이유는 L 값이 감당 못 할 만큼 커지기 때문이다.
⑤ 소속 한 줄 — LC 4형제 = 하틀리 · 콜피츠 · 클랩 · 암스트롱 / RC 2형제 = 위상천이 · 윈브리지 / 수정 = 혼자. "LC 넷, RC 둘, 수정 하나" 로 개수까지 세어 두면 소속을 바꿔 놓은 오답 보기가 바로 걸린다.
📌 주파수 안정도 순위 (시험 빈출)
수정 발진기 > LC 발진기 > RC 발진기
· 수정: Q값 매우 높음 (수만~수십만) → 초정밀
· LC: 고주파(MHz~GHz)에 적합
· RC: 저주파(Hz~kHz)에 적합 (LC는 저주파에서 L값이 너무 커짐)
⚠ 시험 핵심 포인트 (반드시 외울 것)
· 바크하우젠 조건: Aβ = 1 (진폭) + ∠Aβ = 0° (위상)
· Aβ > 1 → 클리핑 / Aβ = 1 → 지속 / Aβ < 1 → 소멸
· 정궤환 폐루프 이득: A1−Aβ · 부궤환: A1+Aβ
· 위상 천이 발진기 = RC 3단으로 180° 회전 (각 단 60°)
· 안정도: 수정 > LC > RC
· 하틀리·콜피츠·클랩 = LC / 위상천이·윈브리지 = RC

PSH = "지금 있는 것 전부 빨리 올려라"

URG = "이 부분만 먼저 처리하라"
　→ 순서를 건너뛴다. 긴급 포인터로 위치 지정

RST vs FIN

FIN = 정상 종료. "할 말 다 했다"
　→ 4-way 절차를 밟는다. 남은 데이터 전송 보장

RST = 비정상 강제 종료. "그만!"
　→ 절차 없이 즉시 끊음. 버퍼 데이터 버려진다

🧠 FIN은 인사하고 나가기, RST는 문 쾅 닫기

⚠️ 자주 나오는 진술
• ACK는 연결 수립 후 거의 항상 1이다 — "ACK가 켜져 있으면 응답 번호 필드가 유효하다"는 뜻
• SYN과 FIN은 각각 순서 번호를 1 소비한다 (데이터가 없어도)
• "제어 비트는 각 1바이트"는 오답 — 각 1비트다
• URG를 켜면 긴급 포인터 필드가 유효해진다 — 이 짝은 시험 단골
🔗 3-way / 4-way 핸드셰이크의 전체 흐름과 TCP 상태 전이는 「4계층 — 전송」 섹션에 정리되어 있다 → 바로 가기

CSMA/CD vs CSMA/CA 완전 정복

CSMA = Carrier Sense Multiple Access (반송파 감지 다중 접속)
여러 장치가 하나의 전송 매체를 공유할 때 충돌을 어떻게 처리하느냐에 따라 CD와 CA로 나뉨

CD = Collision Detection (충돌 감지) → 유선 이더넷 (802.3)
CA = Collision Avoidance (충돌 회피) → 무선 LAN (802.11)

CSMA/CD 상세 동작

왜 유선에서만 CD가 가능한가?

유선: 자신이 보내는 신호 + 수신 신호를 동시에 비교 가능
→ 신호 차이가 생기면 "충돌 발생" 감지

무선: 전송 중에는 수신을 못 함 (반이중 통신)
→ 자신의 신호가 너무 강해서 충돌 신호를 감지할 수 없음

CSMA/CD 동작 순서: 1. CS (Carrier Sense) → 채널이 사용 중인지 먼저 확인 │ ├─ 사용 중 → 대기 (채널이 빌 때까지) │ └─ 비어있음 → 전송 시작 │ ├─ 충돌 없음 → 전송 완료 ✓ │ └─ 충돌 감지 → JAM 신호 전송 (모두에게 충돌 알림) │ └─ 랜덤 시간 대기 (백오프 알고리즘) │ └─ 재전송 시도
단계동작설명
1. CS채널 감지전송 전 채널이 사용 중인지 확인
2. MA다중 접속채널 비어있으면 동시에 여러 장치가 접근 가능
3. CD충돌 감지전송 중 충돌 발생 시 즉시 감지
4. JAM충돌 알림모든 장치에 충돌 발생 알림 신호 전송
5. 백오프랜덤 대기이진 지수 백오프로 랜덤 시간 대기 후 재전송
이진 지수 백오프 (Binary Exponential Backoff):
충돌 횟수가 늘어날수록 대기 시간 범위가 2배씩 증가
1차 충돌: 0~1 중 랜덤 / 2차: 0~3 중 랜덤 / 3차: 0~7 중 랜덤...
→ 최대 16회 재시도 후 실패 처리
CSMA/CA 상세 동작

왜 무선에서는 CA(회피)를 쓰는가?

무선은 충돌을 감지할 수 없기 때문에
충돌이 발생하기 전에 미리 회피해야 함

방법: 전송 전 채널 감지 + 랜덤 대기(IFS) + ACK 확인
→ 충돌 가능성을 최소화

CSMA/CA 동작 순서: 1. CS (Carrier Sense) → 채널이 사용 중인지 확인 │ ├─ 사용 중 → 대기 │ └─ 비어있음 → IFS 대기 (Inter Frame Space, 일정 시간 대기) │ └─ 백오프 카운터 시작 (랜덤 슬롯 대기) │ └─ 전송 시작 │ ├─ ACK 수신 → 성공 ✓ │ └─ ACK 없음 → 재전송
단계동작설명
1. CS채널 감지전송 전 채널 사용 여부 확인
2. IFS프레임 간 공간일정 시간 추가 대기 (충돌 회피)
3. 백오프랜덤 슬롯 대기랜덤 시간 추가 대기
4. 전송데이터 전송채널 확보 후 전송
5. ACK수신 확인수신측이 ACK 전송. 없으면 재전송
CSMA/CA 보조 메커니즘 — RTS/CTS
숨겨진 노드 문제 (Hidden Node Problem):
A와 C가 서로 못 보는 위치에 있을 때 둘 다 B에 동시 전송 → 충돌
→ 이 문제를 해결하기 위해 RTS/CTS 사용
RTS/CTS 동작: 송신측 ──── RTS (Request To Send) ────▶ AP "나 보내도 돼?" AP ◀─── CTS (Clear To Send) ────── AP "응, 보내도 돼. 다른 장치들은 대기" 송신측 ──── 데이터 전송 ──────────────▶ AP AP ◀─── ACK ────────────────────── 수신측
동작 방식 핵심 차이 정리

CSMA/CD — "충돌 나면 다시"

감지 → 전송 → 충돌 감지
→ JAM 신호 → 랜덤 대기 → 재전송

충돌: 사후 처리
장점: 구현 간단
단점: 충돌 많을수록 효율 저하
현재: 스위치 보급으로 거의 사용 안 함

CSMA/CA — "충돌 안 나게 먼저"

감지 → IFS 대기 → 백오프
→ 전송 → ACK 확인

충돌: 사전 예방
장점: 충돌 최소화
단점: 대기 시간으로 오버헤드 발생
현재: 모든 Wi-Fi 환경에서 사용

⚠ 시험 단골 출제 포인트
· CD = 충돌 감지(Detection) = 유선(802.3) / CA = 충돌 회피(Avoidance) = 무선(802.11)
· 무선에서 CD 불가 이유: 반이중 통신이라 전송 중 수신 불가
· CSMA/CA에서 충돌 감지 대신 ACK로 수신 확인
· RTS/CTS: 숨겨진 노드 문제 해결용 보조 메커니즘
· 백오프 알고리즘: CD=이진지수백오프 / CA=랜덤슬롯백오프

📡 전파의 파장 (Wavelength)
핵심 공식
λ = cf
λ = 파장(m)  ·  c = 광속 = 3 × 10⁸ m/s  ·  f = 주파수(Hz)
(전파는 빛과 같은 전자기파 → 진공·공기 중 속도 = 광속)
관련 공식
· 전파 속도: v = f × λ (속도 = 주파수 × 파장)
· 주기: T = 1f (주파수의 역수)

예제 1 — 주파수 → 파장

Q: 100[MHz] 전파의 파장은?

λ = cf = 3×10⁸100×10⁶
= 3×10⁸10⁸ = 3 m

예제 2 — 1GHz 파장

Q: 1[GHz] 전파의 파장은?

λ = 3×10⁸1×10⁹
= 0.3 m = 30 cm

🔊 데시벨(dB) — 10log vs 20log
왜 10log와 20log로 나뉘나?
전력은 전압의 제곱에 비례 (P ∝ V²) → log(V²) = 2·log(V)
따라서 전압비는 10log 앞에 ×2 → 20log가 됨
구분공식적용 대상
전력비dB = 10 logP₂P₁전력(Power), 신호 세기(W)
전압·전류비dB = 20 logV₂V₁전압(V), 전류(A), 진폭
📶 SNR (신호대잡음비, Signal-to-Noise Ratio)
SNR = 신호 전력(S) / 잡음 전력(N)
값이 클수록 신호가 잡음보다 강함 → 통신 품질 좋음
표현공식비고
S/N (신호대잡음) 전력10 log(S/N)전력비 — 클수록 좋음 ↑
S/N 전압20 log(Vs/Vn)전압비
N/S (잡음대신호)10 log(N/S)
= −10 log(S/N)		S/N의 부호 반전 (역수)

예제 3 — 전압비 SNR

Q: 신호 전압 100[mV], 잡음 전압 1[mV] 일 때 SNR[dB]?

SNR = 20 log(100/1)
= 20 log(100) = 20 × 2
= 40 dB

Q: 신호 전력이 잡음의 1000배일 때 SNR[dB]?

SNR = 10 log(1000)
= 10 × 3 = 30 dB

(log 1000 = 3)

🎚️ PCM · 표본화 · 양자화 잡음

PCM(Pulse Code Modulation) = 아날로그 음성을 디지털 비트열로 바꾸는 표준 방식. 표본화 → 양자화 → 부호화 세 단계가 핵심이고, 시험 계산 문제는 거의 전부 이 세 단계에서 나온다.
🔄 PCM 처리 과정 — 순서 암기
[송신] 아날로그 → 표본화 → 양자화 → 부호화 → 디지털 전송 Sampling Quantizing Encoding [수신] 디지털 → 복호화 → 여파(보간) → 아날로그 복원 Decoding Filtering
⚠ 순서 함정 — "표본화 → 부호화 → 양자화" 는 오답. 반드시 양자화가 부호화보다 먼저다. 양자화로 값을 정한 뒤에야 그 값에 비트를 붙일 수 있다.

② 양자화 (Quantizing) — 양자화 잡음의 정체

표본으로 뽑은 연속적인 진폭을 유한 개의 레벨로 반올림하는 과정. n비트로 부호화하면 레벨 수는 2ⁿ개다. 반올림하면서 버려지는 차이가 양자화 오차이고, 이것이 잡음처럼 들리므로 양자화 잡음이라 부른다.

실제 값 ─── 2.7 ────────── 양자화 레벨 3으로 반올림 ↑ 오차 0.3 ← 이것이 양자화 잡음 (최대 ± Δ/2) Δ(스텝 크기) = 전체 진폭 범위 ÷ 2ⁿ

② 비선형 양자화(압신) — 전송률을 늘리지 않고 작은 신호의 S/N만 개선한다
📐 압신 (Companding) — 비선형 양자화

균등 양자화는 작은 신호일수록 상대적 오차가 커진다. 그래서 송신에서 작은 신호를 압축(Compressing) 해 크게 부풀려 양자화하고, 수신에서 신장(Expanding) 해 되돌린다. 두 단어를 합쳐 Compander(압신기).

③ 부호화 · PCM 전송률 계산
R = fs × n [bps]
전송률 = 표본화 주파수 × 양자화 비트 수  ·  채널 M개면 × M
📖 기출 계산 ① — 4 kHz 음성을 8비트로 PCM 부호화할 때 전송률은?
① fs = 2 × 4 kHz = 8 kHz
② R = 8,000 × 8 = 64,000 bps = 64 kbps  ← 전화 1채널(DS-0)의 근거
📖 기출 계산 ② — 24채널을 시분할 다중화한 T1의 전송률은?
① 채널당 8비트 × 24채널 = 192비트, 프레임 동기비트 1개 추가 → 193 비트/프레임
② 프레임은 초당 8,000회(125μs마다) → 193 × 8,000 = 1.544 Mbps
E1은 32타임슬롯(음성 30 + 동기 1 + 신호 1) × 8비트 × 8,000 = 2.048 Mbps
PCM 신호의 소요 대역폭 — 나이퀴스트에 따라 대역폭 ≈ 전송률 ÷ 2. 64 kbps PCM은 약 32 kHz 가 필요하다. 원래 음성 4 kHz의 8배 — 디지털화의 대가다.

💡 광통신 이론 — 시스템 · 광원 · 수광 · 증폭 (1과목)

광섬유가 길이라면, 광통신 이론은 그 길 위를 달리는 차와 신호등이다. 전기를 빛으로 바꾸는 광원, 빛을 다시 전기로 되돌리는 수광소자, 중간에서 힘을 보태는 광증폭기 — 이 셋이 핵심이다.

[전기신호] │ ▼ 광 송신기 ── 구동회로 + 광원(LED / LD) ── 전기 → 빛 (E/O 변환) │ ▼ 광섬유 전송로 ── 코어 안에서 전반사로 진행 · 손실과 분산 발생 │ ▼ 광 중계기 / 광증폭기(EDFA) ── 약해진 빛을 다시 키움 │ ▼ 광 수신기 ── 수광소자(PIN-PD / APD) + 증폭·판정 ── 빛 → 전기 (O/E 변환) │ ▼ [전기신호]

✅ 광섬유의 장점

• 광대역 — 수 THz급, 대용량 전송
• 저손실 — 1550nm에서 0.2 dB/km
• 전자기 유도 무관 — 잡음·누화 없음
• 도청 곤란 — 보안성 우수
• 가늘고 가벼움 · 부식 없음
• 중계 간격이 김 (수십~100km)

⚠ 단점

• 접속·분기가 어렵다 (융착 접속기 필요)
• 기계적 강도가 약하고 구부림에 취약
• 전기를 함께 보낼 수 없음(급전 불가)
• 시험·측정 장비가 고가 (OTDR)
• 단면을 눈으로 보면 위험 (적외선)

🔀 비트전송률 vs 변조속도 — 시험 최다 출제!
비트전송률 (Bit Rate)
· 1초당 전송되는 비트(bit) 수
· 단위: bps (bits per second)
· 별칭: 정보전송속도, 데이터 신호속도
변조속도 (Baud Rate)
· 1초당 신호(심볼) 변화 횟수
· 단위: baud (보)
· 별칭: 신호속도, 보율
· = 1펄스시간(T)
핵심 공식
비트전송률 = 변조속도 × log₂M
bps = Baud × log₂M  (M = 변조 진수 = 데이터 준위 수)
변조속도 Baud = 1펄스시간(T)  ·  log₂M = 신호 1개당 비트 수

👁️ 왜 baud와 bps가 다른가 — 한 장으로
1초 동안 신호가 4번 바뀌었다 → 변조속도는 무조건 4 baud 2진 (심볼당 1비트) 1 0 1 1 → 4 bps (bps = baud) 4진 (심볼당 2비트) 10 01 11 00 → 8 bps (bps = 2×baud) 8진 (심볼당 3비트) 101 011 110 001 → 12 bps (bps = 3×baud) 16진 (심볼당 4비트) 1010 0110 1100 0011 → 16 bps (bps = 4×baud) 신호가 바뀐 횟수는 같은데, 한 번에 몇 비트를 싣느냐가 다르다.
그래서 bps는 항상 baud보다 크거나 같다. 두 값이 같아지는 것은 2진(2준위)일 때뿐이다. "bps가 baud보다 작을 수 있다"는 보기는 무조건 오답이다.
📶 대역폭과의 관계 — 나이퀴스트로 이어진다
대역폭 B [Hz] 인 채널에서 최대 변조속도 = 2B [baud] ← 신호를 이보다 빨리 바꿀 수는 없다 최대 비트전송률 = 2B · log₂M [bps] ← 나이퀴스트 채널용량 공식 즉 대역폭이 보율의 한계를 정하고, 진수(M)를 올려야 bps가 올라간다.
⚠ 진수를 무한정 올리지 못하는 이유 — M을 키우면 신호 준위 간격이 촘촘해져 잡음에 취약해진다. 그래서 실제 한계는 잡음까지 반영한 샤논 공식이 정한다. 대역폭을 늘리지 않고 속도를 올리는 방법이 다진 변조(QAM 등) 인 셈이다.
🧮 추가 예제 — 역산 유형
예제 ① 데이터 신호속도가 9,600[bps]인 8진 위상변조(8-PSK) 의 변조속도는?
8진 → log₂8 = 3비트  →  Baud = 9,600 ÷ 3 = 3,200 [baud]
예제 ② 변조속도 1,200[baud]로 쿼드비트 전송 시 데이터 신호속도는?
쿼드비트 = 4비트(16진)  →  bps = 1,200 × 4 = 4,800 [bps]
예제 ③ 펄스 폭이 0.5[ms] 이고 8진 신호일 때 비트전송률은?
① Baud = 1 ÷ (0.5×10⁻³) = 2,000 baud
② bps = 2,000 × log₂8 = 2,000 × 3 = 6,000 [bps]
예제 ④ 9,600[baud] 모뎀에서 2개의 비트를 1개의 신호로 변조했을 때 전송속도[bps]는? 기출 유형
① "비트 2개 = 신호 1개" → 심볼당 2비트 → 4진(QPSK), 디비트
② bps = Baud × 심볼당 비트 = 9,600 × 2 = 19,200 [bps]
트럭으로 생각하기 1초에 트럭이 9,600대 지나갔다 → 9,600 baud (신호가 바뀐 횟수) 트럭 한 대에 짐을 2개씩 실었다 → 심볼당 2비트 그럼 짐은 모두 몇 개인가? → 9,600 × 2 = 19,200 bps “2개의 1비트가 1개의 신호로” = “트럭 한 대에 짐 2개” 라는 뜻이다.
⚠ 이 유형의 유일한 함정 — 방향
9,600 ÷ 2 = 4,800 을 고르기 쉽다. 확인법은 하나다 — bps는 절대 baud보다 작을 수 없다. 트럭 수보다 짐이 적을 수는 없으니까. 답이 baud보다 작게 나왔다면 곱셈과 나눗셈을 뒤집은 것이다.
나누는 것은 반대 방향 문제(bps를 주고 baud를 물을 때)이다.
💡 실무 참고 — UART·RS-232에서 말하는 "보드레이트 9600"은 심볼 하나가 1비트(2진)라 9,600 baud = 9,600 bps 로 값이 같다. 그래서 현장에서 두 용어를 섞어 써도 문제가 없지만, 모뎀·QAM처럼 다진 변조를 쓰는 순간 두 값은 달라진다. 시험은 바로 이 지점을 묻는다.
⚠ 시험 핵심 포인트
· bps = Baud × log₂M (M = 진수 = 데이터 준위 수)
· 변조속도 = 1펄스시간 (펄스시간만 주어지면 역수 먼저!)
· 2진(2준위)일 때만 bps = baud (값 같음) — 나머지는 bps가 더 큼
· 변조속도·신호속도·보율 = baud / 정보전송속도·데이터신호속도 = bps
· 4진=디비트(2bit), 8진=트리비트(3bit), 16진=쿼드비트(4bit)

🚀 변환 요령 — 이 5가지가 전부
① 2진수 → 10진수  자릿값을 더한다
1 1 0 1 1(2) ↓ 각 자리에 자릿값을 붙인다 16 8 4 2 1 1 1 0 1 1 ↓ 1인 자리만 더한다 16 + 8 + 0 + 2 + 1 = 27
💡 1이 있는 자리만 더하면 끝. 0인 자리는 계산할 필요가 없다.
② 10진수 → 2진수  2로 나누고 나머지를 거꾸로 · 교과서 방식
27 ÷ 2 = 13 … 1 ↑ 13 ÷ 2 = 6 … 1 │ 아래에서 6 ÷ 2 = 3 … 0 │ 위로 3 ÷ 2 = 1 … 1 │ 읽는다 1 ÷ 2 = 0 … 1 ↑ → 11011(2)
💡 더 빠른 방법 — 큰 자릿값부터 빼기. 27에서 16을 빼면 11, 11에서 8을 빼면 3, 3에서 2를 빼면 1, 1에서 1을 빼면 0. 뺀 자리는 1, 못 뺀 자리는 0 → 16(1) 8(1) 4(0) 2(1) 1(1) = 11011. 나눗셈보다 훨씬 빠르다.
③ 2진수 ↔ 8진수  소수점 기준으로 3비트씩 묶는다
1 0 1 1 0 1 0(2) ↓ 오른쪽부터 3개씩 끊고, 모자라면 왼쪽에 0을 채운다 001 011 010 1 3 2 → 132(8)
💡 8 = 2³ 이라서 딱 3비트. 반대로 8진수 → 2진수는 각 자리를 3비트로 펼치면 된다. (7 → 111)
④ 2진수 ↔ 16진수  4비트씩 묶는다 — 가장 많이 쓰임
1 1 0 1 0 1 1 0(2) ↓ 오른쪽부터 4개씩 끊는다 1101 0110 13 6 → D 6 → D6(16)
💡 16 = 2⁴ 이라서 딱 4비트. 위의 4비트 대응표만 외우면 바로 읽힌다.
1바이트(8비트) = 16진수 정확히 2자리 → MAC 주소·IP·색상코드가 16진수인 이유.
⑤ 8진수 ↔ 16진수  직접 하지 말고 2진수를 경유

📝 시험 포인트
• 2진 ↔ 8진 = 3비트씩, 2진 ↔ 16진 = 4비트씩 묶기 (8=2³, 16=2⁴)
• 8진 ↔ 16진은 반드시 2진수를 경유
• 10진 → 2진은 큰 자릿값부터 빼기가 나눗셈보다 빠름
• 음수 표현은 2의 보수 (1의 보수 + 1)
• 1바이트 = 8비트 = 16진수 2자리, 2¹⁰ = 1,024
• BCD는 1010 ~ 1111을 사용하지 않는다

🔤 자료 표현 · 코드 체계 (5과목)

컴퓨터는 0과 1밖에 모른다. 그래서 숫자·문자·부호를 어떤 규칙으로 0과 1에 대응시킬 것인가 가 문제가 되고, 그 규칙들이 곧 코드 체계다. 진수 변환이 계산이라면 이 단원은 약속을 다룬다.
📦 자료의 단위
비트(Bit) ─ 0 또는 1, 정보의 최소 단위 └ 니블(Nibble) = 4비트 = 16진수 한 자리 └ 바이트(Byte) = 8비트 = 문자 1개 = 16진수 두 자리 └ 워드(Word) = CPU가 한 번에 처리하는 단위 (Half 2 / Full 4 / Double 8 byte) └ 필드 → 레코드 → 파일 → 데이터베이스
🔢 수치 자료 표현 — 고정소수점 vs 부동소수점
방식구조특징
부호와 절대치맨 앞 1비트 = 부호, 나머지 = 크기 가장 단순하지만 0이 +0과 −0 두 개로 표현됨
1의 보수모든 비트 반전 8비트 범위 −127 ~ +127. 역시 0이 두 개
2의 보수1의 보수 + 1 8비트 범위 −128 ~ +127. 0이 하나뿐 → 실제로 사용되는 방식
부동소수점부호(1) + 지수부 + 가수부 표현 범위가 매우 넓음. 대신 연산이 느리고 회로가 복잡
팩 / 언팩 10진10진수를 4비트씩 묶어 저장 팩은 1바이트에 두 자리, 언팩은 한 자리. 사무·금융 연산용
📖 2의 보수 표현 범위 공식
n비트 2의 보수 → −2ⁿ⁻¹ ~ +(2ⁿ⁻¹ − 1)
8비트 → −128 ~ +127  ·  16비트 → −32,768 ~ +32,767
음수 쪽이 하나 더 많은 이유는 0을 양수 쪽에서 한 자리 쓰기 때문이다.
부동소수점 정규화 — 가수부의 첫 자리가 0이 되지 않도록 소수점 위치를 조정하는 것. 같은 값을 여러 방식으로 표현할 수 있는 문제를 없애고 정밀도를 최대로 확보한다.

✂️ 논리식 간소화 — 단계별 예제
예제 ①   F = A·B + A·B' + A'·B 를 간소화하면?
F = A·B + A·B' + A'·B
  = A·(B + B') + A'·B   ← 분배(A로 묶기)
  = A·1 + A'·B         ← 보수 B+B'=1
  = A + A'·B           ← 항등 A·1=A
  = (A + A')·(A + B) ← 분배
  = 1·(A + B) = A + B
예제 ②   F = A + A'·B 를 한 줄로 (자주 나오는 형태)
A + A'·B = A + B   /   A·(A' + B) = A·B
보수가 붙은 항 앞의 보수는 지워진다 — 흡수 법칙의 변형. 통째로 외워두면 빠르다
🔧 드모르간 활용 — NAND 하나로 다 만들기
NAND가 만능 게이트인 이유 NOT : A NAND A = (A·A)' = A' AND : (A NAND B) NAND (A NAND B) = ((A·B)')' = A·B OR : (A NAND A) NAND (B NAND B) = A' NAND B' = (A'·B')' = A + B ← 드모르간 세 가지를 다 만들 수 있으므로 모든 논리회로를 NAND만으로 구현할 수 있다. NOR 도 같은 이유로 만능 게이트다.
왜 만능 게이트를 쓰는가 — 공정에서 한 종류의 게이트만 대량 생산하면 되므로 단가가 내려가고 집적도가 올라간다. "NAND/NOR가 만능 게이트인 이유"를 묻는 문제의 근거가 바로 위 세 줄이다.
🗺️ 카르노맵 (Karnaugh Map) — 논리식 간소화

불 대수 법칙을 하나씩 적용해 식을 줄이는 것은 실수하기 쉽다. 카르노맵은 진리표를 격자로 그려 놓고 눈으로 묶어 최소 논리식을 얻는 방법이다. 게이트 수를 줄여 회로를 단순하게 만드는 것이 목적이다.

핵심 — 칸 배열이 그레이 코드 순서다 BC A 00 01 11 10 ← 01 다음이 11 (10이 아니다!) 0 · · · · 1 · · · · 이렇게 배열해야 이웃한 칸이 딱 1비트만 달라진다. 그래야 묶었을 때 변하는 변수가 사라진다.
묶기 규칙내용
개수1, 2, 4, 8 … 2의 거듭제곱 개씩만 묶는다 (3개·5개 묶기 불가)
크기최대한 크게 묶는다 — 크게 묶을수록 변수가 많이 사라진다
중복이미 묶인 1을 다시 묶어도 된다
인접상하좌우로만 인접. 맨 왼쪽과 맨 오른쪽, 맨 위와 맨 아래도 인접(맵이 원통처럼 감김)
결과 읽기묶음 안에서 값이 변하는 변수는 삭제, 변하지 않는 변수만 남긴다

🔁 보수를 이용한 뺄셈 — 감산기가 따로 없는 이유
A − B = A + (B 의 2의 보수)
실제 컴퓨터는 감산 회로를 따로 두지 않고, 가산기 하나로 덧셈과 뺄셈을 모두 처리한다. 각 비트에 XOR 게이트를 달고 제어선 M 을 두면 M=0 → 덧셈, M=1 → 뺄셈이 된다 (M=1 이면 B 가 반전되고 최하위 자리올림에 1 이 들어가 자동으로 2의 보수가 만들어진다).
