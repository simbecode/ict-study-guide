🖥️ 명령어 사이클 · CPU 구조 (5과목)

명령어 사이클(Instruction Cycle) = CPU가 하나의 명령어를
메모리에서 가져와 실행하는 전 과정. 이 사이클을 반복하며 프로그램 수행.
🔄 명령어 사이클 4대 단계
📥
인출 Fetch
명령어를 메모리→CPU
🔗
간접 Indirect
간접주소 실제주소 인출
⚙️
실행 Execute
명령어 실제 수행
🚨
인터럽트 Interrupt
인터럽트 발생 시 처리
기본 흐름: 인출(Fetch) → 해독(Decode) → 실행(Execute) → (필요시 인터럽트)
📋 CPU 주요 레지스터 (시험 빈출!)
레지스터이름역할
PCProgram Counter
프로그램 카운터		다음에 실행할 명령어의 주소 저장
IRInstruction Register
명령어 레지스터		현재 실행 중인 명령어 저장
MARMemory Address Register
메모리 주소 레지스터		접근할 메모리 주소 저장
MBR
(MDR)		Memory Buffer Register
메모리 버퍼 레지스터		메모리와 주고받는 데이터 임시 저장
ACAccumulator
누산기		연산 결과 저장
⚡ 인출(Fetch) 사이클 마이크로연산 (자주 출제)
t0: MAR ← PC (PC의 주소를 MAR로 복사) t1: MBR ← Memory[MAR], PC ← PC+1 (명령어 인출 + PC 증가) t2: IR ← MBR (명령어를 IR로 이동)
⏱ 명령어 실행 시간 계산
명령어 실행 시간 = 클럭 주기 × 필요 클럭 수
클럭 주기 = 1 / 클럭 주파수
예) 1[GHz] CPU → 클럭 주기 = 1/10⁹ = 1[ns] → 4클럭 명령어 = 4[ns]
⚠ 시험 핵심 포인트
· PC = 다음 명령어 주소 / IR = 현재 명령어 (구분!)
· MAR = 주소 / MBR(MDR) = 데이터
· 명령어 사이클: 인출 → 간접 → 실행 → 인터럽트
· 인출 단계 마이크로연산: MAR←PC, MBR←M[MAR], IR←MBR
· 명령어 시간 = 클럭 주기 × 클럭 수, 클럭 주기 = 1주파수

💻 운영체제 기초 (5과목)

운영체제의 목적 4가지 — 처리능력(Throughput) ↑ · 반환시간(Turnaround Time) ↓ · 신뢰도(Reliability) ↑ · 사용 가능도(Availability) ↑. 이 네 개를 성능 평가 기준으로 그대로 묻는다.

PCB(Process Control Block) — 프로세스마다 하나씩 만들어지는 정보 블록. 프로세스 ID·상태·프로그램 카운터·레지스터·우선순위·자원 정보를 담는다. 문맥 교환(Context Switching) 은 이 PCB를 저장·복원하는 작업이다.

🗂️ 자료구조 · 알고리즘 (5과목)

📦 선형 구조
구조특징대표 응용
배열연속된 공간, 인덱스로 즉시 접근 O(1). 삽입·삭제는 비쌈정적 테이블
연결 리스트포인터로 연결. 삽입·삭제 쉬움, 임의 접근 불가동적 메모리
스택LIFO (후입선출). Top에서만 삽입(Push)·삭제(Pop)함수 호출·재귀·인터럽트 복귀주소, 수식 변환, 되돌리기
큐FIFO (선입선출). Rear 삽입, Front 삭제버퍼·스케줄링·프린터 대기열
데크Deque양쪽 끝에서 삽입·삭제 모두 가능스택+큐 겸용
🌳 트리 순회 — 계산 문제 단골
A ╱ ╲ B C ╱ ╲ D E 전위(Preorder) 뿌리 → 왼쪽 → 오른쪽 A B D E C 중위(Inorder) 왼쪽 → 뿌리 → 오른쪽 D B E A C 후위(Postorder) 왼쪽 → 오른쪽 → 뿌리 D E B C A
이름 외우는 법 — 뿌리(Root)를 언제 방문하느냐로 정해진다. 전위 = 앞, 중위 = 가운데, 후위 = 뒤. 왼쪽이 오른쪽보다 먼저인 것은 세 방식 모두 동일하다.
🔢 정렬 알고리즘 — 시간 복잡도
알고리즘평균최악특징
버블 정렬O(n²)O(n²)인접한 두 개를 비교·교환. 가장 단순
선택 정렬O(n²)O(n²)최솟값을 골라 앞으로
삽입 정렬O(n²)O(n²)거의 정렬된 자료에 유리 (최선 O(n))
퀵 정렬O(n log n)O(n²)피벗 기준 분할. 평균 가장 빠름
병합 정렬O(n log n)O(n log n)분할 정복. 안정적, 추가 메모리 필요
힙 정렬O(n log n)O(n log n)힙 자료구조 이용, 추가 메모리 불필요
⚠ 함정 — 퀵 정렬은 평균 O(n log n)이지만 최악은 O(n²) 이다. "항상 O(n log n)"인 것은 병합·힙 정렬이다.
🔍 탐색 · 해싱
방법복잡도조건 · 특징
선형(순차) 탐색O(n)정렬 불필요. 처음부터 순서대로
이진 탐색O(log n)반드시 정렬되어 있어야 함. 중간값과 비교해 절반씩 줄임
해싱O(1)해시 함수로 주소를 직접 계산. 충돌(Collision) 과 오버플로 처리 필요
해싱 충돌 해결 — 선형 조사법(다음 빈 칸으로) · 이차 조사법 · 체이닝(연결 리스트로 매달기) · 재해싱
해시 함수 — 제산법(나머지) · 중간제곱법 · 폴딩법 · 기수변환법
📝 시험 포인트
• 스택 = LIFO(함수 호출·인터럽트 복귀), 큐 = FIFO(버퍼·스케줄링)
• 트리 순회 — 뿌리를 언제 방문하는가가 이름. 전위 ABDEC / 중위 DBEAC / 후위 DEBCA
• 이진 탐색은 정렬이 전제, O(log n)
• 퀵 = 평균 O(n log n) · 최악 O(n²) / 병합·힙 = 항상 O(n log n)
• 해싱 = O(1)이지만 충돌 처리 필요

🧹 정규화 (Normalization)
비정규 릴레이션 ↓ 도메인이 원자값만 갖도록 → 1NF ↓ 부분 함수 종속 제거 → 2NF ↓ 이행 함수 종속 제거 → 3NF ↓ 결정자이면서 후보키가 아닌 것 제거 → BCNF ↓ 다치 종속 제거 → 4NF ↓ 조인 종속 제거 → 5NF
암기 문장 — "원 부 이 결 다 조" (원자값 → 부분종속 → 이행종속 → 결정자 → 다치종속 → 조인종속). 정규화의 목적은 이상 현상(Anomaly) 제거 — 삽입 이상·삭제 이상·갱신 이상 세 가지다.
