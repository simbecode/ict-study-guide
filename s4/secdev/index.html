🧠 「계층이 올라갈수록 똑똑하지만 느리다」 — 패킷필터(빠름·멍청) → 상태기반 → 프록시(느림·똑똑). 방화벽은 외부 위협을 막는 장비라 내부자 공격은 막지 못한다는 한계 문장이 자주 출제된다.
🏛️ DMZ — 비무장지대

🔒 VPN — 공중망 위의 사설망
구분내용
IPsec3계층에서 동작. 게이트웨이 간 사이트 간 VPN에 주로 사용
└ AH Authentication Header무결성 + 인증만 제공 — 암호화(기밀성) 없음
└ ESP Encapsulating Security Payload무결성 + 인증 + 암호화(기밀성)
└ 전송 모드페이로드만 보호, 원래 IP 헤더 유지 — 단말 간
└ 터널 모드IP 헤더까지 통째로 감싸고 새 헤더를 붙임 — 게이트웨이 간
SSL/TLS VPN4~7계층. 브라우저만 있으면 접속 — 원격 사용자용
🧠 「AH는 도장, ESP는 봉투」 — AH는 진짜임을 보증할 뿐 내용은 보이고, ESP는 봉투에 넣어 가린다. "기밀성을 제공하지 않는 IPsec 프로토콜은?" → AH.
🪪 사용자 인증 3요소
요소무엇으로 증명예
지식 What you know알고 있는 것패스워드, PIN, 보안질문
소유 What you have가지고 있는 것OTP 토큰, 스마트카드, 인증서
존재 What you are신체 그 자체지문·홍채·얼굴·정맥
행위 What you do행동 특성 (보조 요소)서명 필적, 걸음걸이
2요소 인증(2FA) = 서로 다른 종류를 둘 조합. 비밀번호 + OTP(지식+소유)는 2FA지만, 비밀번호 + 보안질문은 둘 다 '지식'이라 2FA가 아니다.
🖐️ 생체인식 성능 지표
지표의미높으면
FAR 오인식률남을 본인으로 잘못 받아들일 확률보안이 위험
FRR 오거부률본인을 남으로 잘못 거부할 확률사용자가 불편
CER 교차점FAR과 FRR이 같아지는 지점낮을수록 우수한 장비
임계값을 엄격하게 하면 FAR↓ FRR↑, 느슨하게 하면 FAR↑ FRR↓ — 둘은 반비례한다. 그래서 장비의 성능은 CER 하나로 비교한다.
🔑 접근통제 모델
모델누가 권한을 정하나특징
DAC
임의적 접근통제		자원 소유자유연하지만 권한이 번져나가기 쉬움. 일반 OS 파일 권한
MAC
강제적 접근통제		시스템(관리자) 정책보안등급(라벨)으로 강제 — 군·정부용, 가장 엄격
RBAC
역할기반 접근통제		역할(직무)사람이 아닌 역할에 권한 부여 — 인사이동에 강함, 기업 표준
🧠 주체로 외운다 — DAC는 주인(Owner), MAC는 관리자(라벨), RBAC는 역할(Role). "소유자가 마음대로 권한을 줄 수 있다" → DAC, "보안등급에 따라 강제된다" → MAC.
