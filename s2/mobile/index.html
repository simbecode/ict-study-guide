📱 이동통신 1G ~ 5G · 근거리 무선

세대 문제는 「그 세대에서 처음 된 것」 하나만 붙잡으면 된다 — 1G 음성, 2G 문자, 3G 영상통화, 4G 올-IP, 5G 초저지연. 다중접속 방식(FDMA·TDMA·CDMA·OFDMA)이 함께 묶여 나온다.
📶 세대별 비교 — 표 하나로 끝낸다
세대신호다중접속대표 규격처음 가능해진 것
1G아날로그FDMAAMPS이동 중 음성통화
2G디지털TDMA(GSM) · CDMAGSM · CDMA(IS-95)문자(SMS)·디지털 음성
3G디지털W-CDMA · CDMA2000IMT-2000 · HSDPA영상통화·무선인터넷
4G디지털OFDMA(하향) · SC-FDMA(상향)LTE · LTE-AAll-IP(회선교환 폐지)·고속 데이터
5G디지털OFDMA (유연한 뉴머롤로지)5G NR초저지연·초연결(1ms·100만 기기/㎢)
🧠 다중접속 암기 — 「주파수·시간·코드·직교주파수」
FDMA=주파수를 나눔 · TDMA=시간을 나눔 · CDMA=코드를 나눔 · OFDMA=직교 부반송파를 나눔.
무선 다원접속에 WDMA는 없다(WDM은 광통신) — 보기에 끼면 그게 답. 원리 상세는 「다중화 FDM/TDM/CDM」 섹션 참고.
🍯 셀 구조와 주파수 재사용
셀을 육각형으로 그리는 이유 : 원은 겹치거나 빈틈이 생기고, 육각형은 빈틈 없이 채우면서 원에 가장 가깝기 때문 ┌ 셀 반경을 줄인다 (셀 분할, Cell Splitting) │ ├─▶ 같은 주파수를 더 자주 재사용 → 가입자 수용 용량 ↑ ├─▶ 단말 송신 전력 ↓ (배터리 유리) └─▶ 기지국 수 ↑ (비용 ↑), 핸드오버 횟수 ↑
용어내용
주파수 재사용충분히 떨어진 셀에서 같은 주파수를 다시 씀 — 한정된 주파수로 용량을 늘리는 핵심 원리
클러스터서로 다른 주파수를 쓰는 셀의 묶음. 클러스터 크기 K가 작을수록 재사용이 잦아 용량↑, 간섭↑
셀 분할가입자가 몰리는 곳의 셀을 더 잘게 쪼갬
섹터화지향성 안테나로 셀을 3섹터·6섹터로 나눠 간섭 감소
마이크로/피코셀반경이 작은 셀 — 건물 내·지하 등 음영지역 해소
🏗️ 이동통신망 구성요소
[2G/3G] 단말(MS) ── BTS(기지국) ── BSC(제어국) ── MSC(교환국) ── 공중망 │ HLR / VLR (가입자 위치 DB) [4G LTE] 단말(UE) ── eNB(진화형 기지국) ──────────── EPC(코어망) BTS+BSC가 하나로 합쳐짐 ├ MME : 이동성·인증 제어 ├ S-GW : 데이터 중계 ├ P-GW : 외부망 연결 게이트웨이 └ HSS : 가입자 정보 (HLR의 후신)
요소역할
BTS 기지국단말과 무선 신호를 주고받는 최전선
BSC 제어국여러 BTS를 묶어 무선 자원·핸드오버 제어
MSC 이동교환국호 교환·라우팅, 공중전화망 연동
HLRHome Location Register — 가입자의 원적지 정보(영구 DB)
VLRVisitor Location Register — 지금 방문 중인 지역의 임시 DB
🧠 HLR vs VLR — 「본적지 vs 현주소」
HLR = Home, 고향 등본. VLR = Visitor, 지금 머무는 곳의 임시 기록. 단말이 이동하면 VLR이 갱신되고 HLR에 위치를 알린다.
4G에서는 BTS+BSC → eNB로 합쳐지고 HLR → HSS로 바뀐다. 핸드오버 분류는 「핸드오버 / 핸드오프」 섹션 참고.
