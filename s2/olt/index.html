🔌 OLT / ONT / ONU · 광통신 장치

PON(Passive Optical Network) 구조에서 사용되는 핵심 광통신 장치들.
국사(교환국) ↔ 광분배기(Splitter) ↔ 가입자 댁내를 연결하는 FTTH 기반 광가입자망 구성 요소.
📊 OLT / ONU / ONT 비교
장치 정식 명칭 설치 위치 주요 기능
OLT Optical Line
Terminal		 국사(교환국) 내 • 광가입자망의 핵심 헤드엔드 장치
• 여러 ONU/ONT를 제어·관리
• 상위 네트워크(백본)와 연결
• 데이터 집선, 대역폭 할당
ONU Optical Network
Unit		 집합 건물 외부
(공동 밀집지역) 		• 광신호 ↔ 전기신호 변환
• 여러 가입자 공유 단말 장치
• 광분배기에서 수신한 신호를
  각 세대에 분배
ONT Optical Network
Terminal		 가입자 댁내
(집 안) 		• 1가구 전용 광 네트워크 단말
• 광신호 ↔ 이더넷/전화/TV 변환
• 공유기/셋탑박스와 직접 연결
• ONU의 가정용 버전

🌐 백본(Backbone) 네트워크
백본(Backbone): 네트워크 내에서 다양한 하위 네트워크를 연결하는
고속 대용량 핵심 전송망. 인터넷 트래픽의 주요 통로.
① 전송 용량
10Gbps ~ 수백Gbps
DWDM 기술로 용량 확대
② 전송 매체
주로 단일모드 광케이블
장거리 저손실 전송
③ 망 구성
Ring형, Mesh형 구조
이중화로 장애 대비
④ 관련 장비
코어 라우터, DWDM
OLT, SDH/SONET 장비
📋 광가입자망 계층 구조
계층 명칭 설명
1 백본망 ISP 핵심망. 초고속 대용량. 코어 라우터/DWDM 장비
2 집선망(Metro) 지역 집선. 여러 국사 연결. OLT가 위치하는 국사 상위
3 가입자망 OLT → 광분배기 → ONU/ONT → 최종 가입자
📝 기출 포인트
2023년 1회 23번 — PON 구성도에서 ONU 다음에 가입자 댁내에 설치되는 장치명은?
→ ONT(Optical Network Terminal)
2023년 1회 29번 — PON의 특징으로 틀린 것은?
→ 보안성이 우수하다 (틀림 — 광분배기로 공유하여 보안 취약)
핵심 암기 — PON의 수동소자(Passive) = 광분배기(Optical Splitter)
능동소자 없이 전기 공급 불필요 → 유지보수 비용 저렴
💡 3초 암기법
OLT = Line → 국사(L=Line, 선로의 시작점)
ONU = Unit → 공유 단위(여러 가구 공유)
ONT = Terminal → 종단(댁내 최종 단말)
