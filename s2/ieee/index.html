IEEE 802 표준 — OSI 계층 매핑

표준명칭OSI 계층변조/접근방식특징
802.2LLC2계층—Logical Link Control. 데이터링크 상위 서브레이어. 흐름·오류 제어
802.1DSTP2계층—스패닝 트리. 루프 방지
802.1QVLAN 태깅2계층—4byte 태그. VID 12bit. 최대 4094개
802.1X포트 인증2계층EAP네트워크 접속 전 사용자 인증
802.4토큰버스1·2계층토큰 패싱버스형 토폴로지. 충돌 없음. 1~10Mbps. 현재 미사용
802.5토큰링1·2계층토큰 패싱링형 토폴로지. 충돌 없음. 4/16Mbps. 현재 미사용
802.3이더넷1·2계층CSMA/CD유선 LAN. 충돌 감지
802.3uFast Ethernet1·2계층CSMA/CD100Mbps. 100BASE-TX
802.3ab기가비트(UTP)1·2계층CSMA/CD1Gbps. Cat5e UTP
802.11bWi-Fi1·2계층CSMA/CA·DSSS2.4GHz / 11Mbps
802.11aWi-Fi1·2계층CSMA/CA·OFDM5GHz / 54Mbps
802.11gWi-Fi1·2계층CSMA/CA·OFDM2.4GHz / 54Mbps. b 호환
802.11nWi-Fi 41·2계층CSMA/CA·MIMO듀얼밴드 / 600Mbps
802.11acWi-Fi 51·2계층CSMA/CA·MU-MIMO5GHz / ~6.9Gbps
802.15.1블루투스1·2계층FHSS2.4GHz / 3Mbps / ~10m / 피코넷
802.15.4Zigbee1·2계층DSSS초저전력 / 250Kbps / IoT 센서
802.16WiMAX1·2계층OFDM무선 MAN / ~70Mbps / 50km
CSMA/CD vs CSMA/CA: CD=유선(802.3) / CA=무선(802.11)
블루투스 vs Zigbee: BT=FHSS·3M·피코넷 / Zigbee=DSSS·250K·초저전력·IoT
토큰링(802.5) vs 토큰버스(802.4): 둘 다 토큰 패싱 / 링형 vs 버스형 토폴로지 / 4·16Mbps vs 1~10Mbps
⚠ 토큰링 vs 토큰버스 시험 포인트
· 802.4 = 토큰버스 (숫자 4 = 버스Bus의 B 연상)
· 802.5 = 토큰링 (숫자 5 = 링Ring의 R 연상)
· 토큰링 속도 = 4Mbps 또는 16Mbps — 자주 출제!
· 둘 다 현재는 이더넷(802.3)으로 대체됨
📚 IEEE 802 시리즈 전체 계보 — 802.1 ~ 802.22

IEEE 802는 LAN·MAN의 1·2계층을 다루는 표준 묶음이다. 번호 하나에 기술 하나가 대응하므로, "번호 ↔ 기술" 짝 맞추기 형태로 거의 매 회차 출제된다.

번호명칭내용 · 출제 포인트
802.1상위 계층 인터페이스
브리징 · 관리		 LAN/MAN의 브리징과 망 관리 전반. 아래 하위 표준들의 뿌리
802.2LLC 논리링크제어 데이터링크 상위 부계층. 흐름·오류 제어, 상위 프로토콜 식별(DSAP/SSAP)
802.3CSMA/CD 이더넷 유선 LAN의 사실상 표준. 충돌 감지 방식
802.4토큰 버스 버스형 + 토큰 패싱. 1~10Mbps. 공장 자동화(MAP)에 쓰였고 현재 미사용
802.5토큰 링 링형 + 토큰 패싱. 4 / 16 Mbps. IBM 계열. 현재 미사용
802.6DQDB (MAN) 분산 큐 이중 버스 — 도시권 통신망(MAN) 표준 기출
802.7광대역 LAN 자문Broadband TAG — 광대역 전송 기술 권고
802.8광섬유 LAN 자문Fiber Optic TAG — 광 매체 기술 권고
802.9음성 · 데이터 통합 IsoEthernet — 등시성(Isochronous) 서비스로 음성과 데이터를 함께 전송 기출
802.10LAN 보안LAN/MAN Security (SILS)
802.11무선 LAN (Wi-Fi)CSMA/CA. b→a·g→n→ac→ax→be 순으로 빨라짐
802.12100VG-AnyLAN요구 우선순위(Demand Priority) 방식. 100Mbps. 사라진 표준
802.13—결번 (사용하지 않음)
802.14케이블 모뎀HFC 망을 이용한 데이터 전송
802.15WPAN 근거리 개인망블루투스·UWB·지그비. 아래에 별도 표
802.16WMAN (WiMAX) 광대역 무선 접속. 802.16e = 이동형(모바일 와이맥스 · 와이브로)
802.17RPRResilient Packet Ring — 복원력 있는 패킷 링, 이중 링 자동 절체
802.18무선 규제 자문Radio Regulatory TAG
802.19공존성 자문서로 다른 무선 표준 간 간섭 조정
802.20MBWAMobile Broadband Wireless Access — 고속 이동 중 광대역 접속
802.21MIH Media Independent Handover — 이종망 간 핸드오버(Wi-Fi ↔ 셀룰러) 기출
802.22WRANTV 유휴 대역(화이트스페이스)을 이용한 무선 지역망
번호 암기 요령 — 2=LLC · 3=이더넷 · 4=토큰버스 · 5=토큰링 · 6=DQDB(MAN) · 9=음성/데이터 통합 · 11=무선랜 · 15=WPAN · 16=WiMAX · 21=핸드오버. 4와 5(버스/링)와 6·9가 가장 많이 나오고, 13은 결번이라는 것도 함정으로 출제된다.
🔧 802.1 계열 — 브리징 · VLAN · 인증
표준명칭내용
802.1DSTP스패닝 트리 — 루프 방지. 수렴 30~50초
802.1wRSTP빠른 STP — 수렴 수 초로 단축
802.1sMSTPVLAN 그룹별로 여러 개의 스패닝 트리 운영
802.1QVLAN 태깅4바이트 태그, VID 12비트 → 4094개 기출 최다
802.1pQoS 우선순위태그 안의 3비트 우선순위 필드 (8단계)
802.1adQinQ태그를 이중으로 — 통신사업자용 VLAN 확장
802.1X포트 기반 인증접속 전에 사용자 인증 (EAP · RADIUS 연동)
802.1AEMACsec2계층 구간 암호화
⚠ 최다 함정 — 802.1Q = VLAN, 802.1X = 인증, 802.1D = STP, 802.1p = QoS. 네 개를 서로 바꿔 놓은 보기가 반복 출제된다.

표준기술속도 · 거리특징
802.15.1블루투스~3 Mbps / 약 10 m FHSS 주파수 도약, 2.4GHz. 피코넷(마스터 1 + 슬레이브 7) → 스캐터넷

📝 802 시리즈 최종 정리
• 2 = LLC / 3 = CSMA/CD / 4 = 토큰버스 / 5 = 토큰링 / 6 = DQDB(MAN)
• 9 = 음성·데이터 통합, 11 = 무선랜, 15 = WPAN, 16 = WiMAX, 21 = 이종망 핸드오버
• 802.1 계열 — Q=VLAN · X=인증 · D=STP · p=QoS
• 802.3 계열 — ab=기가비트 UTP · af=PoE, 명명은 속도-Base-매체
• 802.15 — .1 블루투스(FHSS) / .4 지그비(DSSS·250kbps)
• 802.13은 결번
