7계층 — 응용 계층 (Application Layer)

역할: 사용자와 직접 맞닿는 계층. 실제 서비스(웹·메일·파일전송 등)를 제공하는 프로토콜이 동작
PDU: 데이터 (Data) | 장비: 게이트웨이, L7 스위치
TIP · 7 → 칠일 내내 쓰는 응용 서비스

일주일 7일, 웹을 보고 메일을 보내고 파일을 주고받는다.

7 → 칠일 내내 쓰는 서비스 → 응용 계층 → HTTP·SMTP·FTP·DNS

브라우저로 웹을 보고 메일 앱으로 메일을 보내는 일상을 떠올리세요. 응용 프로그램이 이용하는 네트워크 서비스와 연결됩니다.

6계층은 데이터의 표현, 7계층은 응용 프로그램이 쓰는 네트워크 서비스. 데이터 단위는 데이터(Data)입니다.

칠일은 숫자 7을 연결하는 암기 장치입니다. 앱 화면 전체가 7계층이라는 뜻은 아니에요.

기능내용
사용자 인터페이스 제공사람이 실제로 쓰는 서비스의 창구. 아래 6개 계층은 사용자가 볼 일이 없다
자원 공유 · 원격 접근원격 파일 접근(FTP·NFS), 프린터 공유, 디렉터리 서비스

네트워크 관리장비 상태 수집·제어 (SNMP · CMIP)
⚠ 헷갈리지 말 것 — 응용 계층은 애플리케이션 그 자체가 아니라, 애플리케이션이 네트워크를 쓰기 위해 사용하는 프로토콜이 동작하는 계층이다. 크롬(브라우저)은 애플리케이션이고, HTTP가 7계층 프로토콜이다.

🔧 장비 · 보안 장비
장비역할
게이트웨이서로 다른 프로토콜 체계를 변환해 연결. 7계층 전 구간을 해석할 수 있는 유일한 장비
L7 스위치URL · 쿠키 · HTTP 헤더 내용을 보고 서버로 분산 (L4는 포트까지만 봄)
프록시 서버대리 요청 · 캐싱 · 접근 통제
WAF웹 공격(SQL 인젝션·XSS) 차단. 7계층 전용 보안 장비
IPS / DDoS 방어침입 탐지·차단, 대량 트래픽 방어
💡 L4 스위치 vs L7 스위치 — L4는 IP + 포트만 보고 나누고, L7은 내용(URL·쿠키) 까지 읽어서 나눈다. 그래서 "/img 는 이미지 서버로, /api 는 API 서버로" 같은 분배는 L7 만 가능하다.

가용성서비스가 정상 응답한 비율 → 가동률 단원
SNMP MIB 폴링장비의 트래픽·CPU·포트 상태 수집. 이상 시 Trap 으로 즉시 통보
🔗 이 계층과 이어지는 단원
📝 7계층 시험 포인트
• PDU = 데이터, 장비 = 게이트웨이 · L7 스위치
• 게이트웨이 = 프로토콜 변환 (7계층 전체를 해석)
• 보안 장비 = WAF · IPS · DDoS 방어
• DNS는 UDP 53, 512바이트 초과 시 TCP 사용
• 망 관리 = SNMP(TCP/IP, 단순) vs CMIP(OSI, 기능 풍부)
• 클라우드로는 SaaS 가 이 계층에 대응
