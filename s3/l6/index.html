6계층 — 표현 계층 (Presentation Layer)

역할: 데이터 형식 변환·암호화·압축. 서로 다른 형식의 데이터를 통일된 형식으로 변환
PDU: 데이터 (Data) | 장비: 전용 장비 없음 (소프트웨어 처리)
TIP · 6 → 육성 → 표현을 바꾸기

육성으로 녹음한 말을, 형식을 바꾸고 압축하고 암호화해 보낸다.

6 → 육성 → 표현 계층 → 형식 변환·압축·암호화

목소리 자체가 6계층이라는 뜻은 아니에요. 녹음한 데이터의 표현을 바꾸는 장면으로 세 기능을 기억하세요.

5계층은 대화를 관리하고, 6계층은 데이터의 표현을 다룹니다. 데이터 단위는 데이터(Data)입니다.

OSI의 기능 분류를 위한 연상 암기법입니다. 실제 암호화·압축 기능은 여러 계층에서 구현될 수 있어요.

기술/프로토콜역할특징

시험 포인트: 6계층 = 암호화(SSL/TLS)·압축·형식변환. "전용 장비 없음"이 자주 출제됨
⚙️ 처리 방법 — 이 계층이 하는 일 (3가지)
① 형식 변환
Translation
서로 다른 시스템의 표현 방식을 통일
코드 변환 (ASCII ↔ EBCDIC)
구문 검색, 바이트 순서 맞추기
② 압축
Compression
전송량을 줄여 효율 향상
무손실 : ZIP · PNG · GZIP
손실 : JPEG · MP3 · MPEG
③ 암호화
Encryption
내용을 읽을 수 없게 변환
SSL / TLS 가 대표
HTTPS의 실제 암호화 담당
⚠ 기출 최다 함정 — "전송 계층 — 코드 변환, 구문 검색" 은 틀린 설명이다. 코드 변환·구문 검색은 6계층(표현) 의 기능이고, 전송 계층은 종단 간 신뢰성·흐름제어·오류제어를 담당한다.
🔤 문자 · 데이터 표현 표준
표준내용
ASCII7비트 문자 코드(128자). 'A'=65=0x41, 'a'=97, '0'=48 → 진수 변환 단원
EBCDICIBM 메인프레임용 8비트 코드. ASCII와 서로 변환이 필요 → 이것이 코드 변환
UTF-8유니코드 가변 길이 인코딩. 영문 1바이트, 한글 3바이트
ASN.1플랫폼 독립적인 데이터 구조 표기법. SNMP·X.509 인증서에서 사용
XDR / BER · DERASN.1을 실제 바이트열로 부호화하는 규칙
🗜️ 압축 — 무손실 vs 손실
구분원본 복원압축률예용도
무손실 (Lossless)완전 복원낮음ZIP · GZIP · PNG · GIF · 허프만 · LZW · RLE문서 · 프로그램 · 데이터
손실 (Lossy)복원 불가높음JPEG · MP3 · MPEG · H.264 · H.265사진 · 음악 · 영상
💡 사람이 잘 못 느끼는 정보를 버려서 압축률을 높이는 것이 손실 압축. CCTV의 H.264/H.265도 여기 속한다 → CCTV 영상 압축 단원
🔐 암호화 — SSL / TLS
항목내용
SSL / TLSSSL의 후속이 TLS. 현재 TLS 1.2 / 1.3 사용. HTTPS(443)의 기반
동작 방식하이브리드 — 비대칭키로 세션키 교환 → 대칭키(AES)로 데이터 암호화
제공 기능기밀성(암호화) + 무결성(MAC) + 인증(인증서)
계층 논쟁OSI로는 표현 계층(6), TCP/IP 실무에서는 전송~응용 사이로 본다. 시험에서는 6계층
