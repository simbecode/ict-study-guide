1계층 — 물리 계층 (Physical Layer)

역할: 0과 1의 비트를 전기·광·무선 신호로 변환하여 물리적으로 전송
PDU: 비트 (Bit) | 장비: 허브, 리피터, 케이블, 커넥터
TIP · ㅣ를 보면 1계층!

리피터의 리·피, 비트의 비에 들어 있는 모음 ㅣ를 숫자 1로 떠올려 보세요.

리피터→ㄹㅣ · ㅍㅣ · 터
비트→ㅂㅣ · 트
→
ㅣ = 1
1계층 · 물리

함께 기억: 리피터는 장비, 비트는 데이터 단위(PDU)예요.

글자 모양을 이용한 연상 암기 팁입니다. 모음 ㅣ가 있는 모든 용어가 1계층이라는 뜻은 아니에요.

전송 매체
매체종류특징
UTP비차폐 꼬임쌍선가장 일반적. Cat5e/Cat6
STP차폐 꼬임쌍선노이즈 차폐. 비용 높음
동축케이블CoaxialTV·구형 이더넷
광케이블SMF/MMF장거리·고속. 빛 신호 사용
장비 역할
장비역할

리피터신호 증폭·재생 (거리 연장)
케이블물리적 전송 매체
커넥터RJ-45, BNC, LC 등
허브 vs 스위치: 허브=1계층(신호 무조건 복사) / 스위치=2계층(MAC 기반 선택 전달) → 스위치가 훨씬 효율적
⚙️ 처리 방법 — 이 계층이 하는 일
기능내용
비트 → 신호 변환0과 1을 전압·빛·전파 로 바꾼다. 반대편에서는 신호를 다시 비트로 되돌린다
전송 부호화 (Line Coding)비트열을 실제 전송에 적합한 파형으로 바꾼다 (NRZ · 맨체스터 · AMI 등)
비트 동기송·수신이 같은 시점에 비트를 읽도록 클럭을 맞춘다. 부호에 타이밍 정보를 심어 해결
전기적 규격전압 레벨, 임피던스, 핀 배치, 커넥터 모양, 최대 전송 거리를 규정
전송 모드 결정단방향 / 반이중 / 전이중, 직렬 / 병렬, 동기 / 비동기
⚠ 물리 계층은 "의미"를 모른다 — 주소도 없고 오류 검출도 하지 않는다. 그저 비트를 그대로 실어 나를 뿐이다. 오류 검출은 2계층부터 시작한다.
📶 전송 부호 (Line Code)
좋은 전송 부호의 조건 — ① 대역폭이 좁을 것 ② 부호가 간단하고 일관성 있을 것 ③ 타이밍(동기) 정보를 포함할 것 ④ DC 성분이 없을 것 ⑤ 오류 검출·정정이 쉬울 것 기출

RZ
Return to Zero		비트 중간에 0으로 복귀좋음있음대역폭을 2배 차지

(0=하강, 1=상승)		우수없음이더넷 10BASE-T 에서 사용. 대역폭 2배

🔧 장비 상세
장비역할주의점
리피터감쇠된 신호를 증폭·재생해 전송 거리를 늘림잡음도 함께 증폭됨. 디지털은 재생(Regeneration) 이라 잡음 누적이 없음
허브들어온 신호를 모든 포트에 그대로 복사 (멀티포트 리피터)충돌 도메인이 하나 → CSMA/CD 충돌 다발. 대역폭을 나눠 씀
모뎀디지털 ↔ 아날로그 변복조변조 방식이 속도를 결정
트랜시버 / SFP전기 ↔ 광 신호 변환 모듈파장·거리별로 모듈이 다름 (SR/LR/ER)
미디어 컨버터UTP ↔ 광 매체 변환거리 연장 목적
패치 패널배선 집중·정리성능이 아닌 관리 편의를 위한 수동 장비
허브 vs 스위치 — 허브는 1계층이라 신호를 무조건 복사하고, 스위치는 2계층이라 MAC을 보고 필요한 포트로만 보낸다. 그래서 허브는 충돌 도메인 1개, 스위치는 포트마다 충돌 도메인이 분리된다.

Eye Pattern		눈 모양이 크고 뚜렷할수록 양호. 지터·잡음 여유를 한눈에 판단오실로스코프

아이 패턴 읽는 법 — 눈(eye)이 위아래로 크면 잡음 여유가 크고, 좌우로 넓으면 타이밍 여유가 크다. 눈이 감기면(닫히면) 오류가 급증한다는 뜻.
